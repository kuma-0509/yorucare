## 話す前に(自分用メモ)

- 今日のゴールは「その場で細部まで固める」ことではなく、**「まずは1か月、試運転をやってみましょう」という合意**をいただくこと。それ以上は求めない。
- 報酬・収益配分などお金が絡む数字の話は、まだ売り上げが立っていない段階では伊藤さんも判断しづらいはず。今日は持ち出さず、試運転を経て形が見えてから改めて相談する。
- 数字や役割の細部(第6節の12項目)は、今日は「これから一緒に決めていく項目」として存在だけ見せる。即答も期限も求めない。
- 伊藤さんの強み(法人・支援機関とのつながり、運動指導の専門性)への敬意を先に言葉にしてから、お願いに入る。
- **法人営業は、個人向け有料サービスが始まってから始める。** 試運転や本編の段階で伊藤さんの法人・支援機関とのつながりを先に使うことはしない。伊藤さんが自分の信頼関係をいつ・どう使うかは、伊藤さん自身が決められる状態を保つ。

```

面談は仕事の確認で精一杯」という声をいただいています。

つまり、支援が薄いのは平日夜間・土日祝。
ここを埋めることが、ヨルケアが役に立てる場所だと考えています。
```

```
今日ご相談したいのは、この空白を埋める仕組みを、

逆算するとこういう流れになります。

  → 振り返り・ブラッシュアップ
  → 無料モニター本編(5か月・21名)

  → 個人向けサービスが始まってから、企業・支援機関への営業を開始
  → 企業から復職後3〜6か月サポートの試験導入を受注(2028年3月まで)

今すぐ21名の本編に飛び込むのではなく、
まず最少3名の試運転で、進行やアプリの入力項目、安全対応の実際の動きを確認してから、

企業への営業は、エビデンスと個人会員という実績ができてから始める設計にしました。
地ならしの期間がない分、受注までの期間は長めに見ています。
```

## 4. なぜ企業受注をゴールにするか(2分)

```
個人向け月5,000円のサービスは、正直に言うと、満席の21名でも二人分の人件費は出ません。
副業として行う分には問題ないですが、ここで稼ぐ設計にはしていません。

個人有料版の役割は、「お金を払ってでも続けたい人がいる」という実績づくりです。
本命は、企業から復職後3〜6か月サポートを受注すること。
1人あたり月3〜5万円 × 3〜6か月で、同じ稼働でも個人向けの約7倍の単価になります。

企業に刺さるのは、症状スコアではなく「休まずに働き続けられたか」。
なので測る指標も、勤怠や仕事のパフォーマンス・活力を主役にして、
「効果があった」とは書かず、「参加者の変化」「完走率」までを参考データとして出す、
という誠実な見せ方にしています。
```

## 想定される質問への準備メモ

- **「本当に企業は買うのか?」** → 対象は、休職から復職して働いている方。障がい福祉サービスの就労定着支援の枠ではなく、企業が自社の社員に対して行う復職後3〜6か月のサポートとして提案する。再休職1件あたりの企業損失を企業自身に試算してもらう提案の仕方をする。厚労省の両立支援の努力義務化(2026年4月〜)は一次情報を確認のうえ根拠として使う。企業へのアプローチは地ならしなしで始まる分、個人会員の実績とエビデンスを最大限の武器として使う。
- **「精神科医・安全対応は大丈夫か?」** → 精神科医・安全責任者は確保済み。5か月仕様の安全対応3段階・尺度使用条件はすでに整理済み(PHQ-9ではなくPHQ-8を採用するなど)。
- **「個人向けで稼げないなら意味があるのか?」** → 個人有料版は収益源ではなく実績づくり。本命は企業受注であることを正直に共有する(4節参照)。
- **「私の負担はどれくらい増えるのか?」** → 週の目安は21名時で運動+疲労回復が約2時間。営業活動は個人向けサービスが始まってから発生する。試運転(最少3名)はこれよりずっと小さい規模から始まる。
- **「なぜ2027年9月から2028年3月に変わったのか?」** → 法人営業を、実績がない段階で伊藤さんのつながりを使って始めるのをやめ、エビデンスと個人会員という実績ができてから始める順番に変えたため。地ならしの期間がなくなる分、受注までの期間を現実的に延ばした。
