# ヨルケア事業化プラン ご相談・ご承認のお願い(伊藤さんへ・話す原稿)

作成日: 2026-09-03
形式: 対面・オンライン打ち合わせ用トーク原稿(所要目安 15〜20分・質疑込み)
対象: 株式会社mimococo 代表 伊藤さん
目的: 「復職後サポート事業化プラン」を初めてご説明し、一緒に取り組むことへのご承認をいただく
参照資料: `docs/business-plan-return-to-work.md`(事業計画本体)

## 話す前に(自分用メモ)

- 今日のゴールは「その場で細部まで固める」ことではなく、**「まずは1か月、試運転をやってみましょう」という合意**をいただくこと。それ以上は求めない。
- 報酬・収益配分などお金が絡む数字の話は、まだ売り上げが立っていない段階では伊藤さんも判断しづらいはず。今日は持ち出さず、試運転を経て形が見えてから改めて相談する。
- 数字や役割の細部(第8節の12項目)は、今日は「これから一緒に決めていく項目」として存在だけ見せる。即答も期限も求めない。
- 伊藤さんの強み(法人・支援機関とのつながり、運動指導の専門性)への敬意を先に言葉にしてから、お願いに入る。

## 1. 導入(1分)

```
お時間いただきありがとうございます。
今日は、これまでヒアリングや準備で積み重ねてきたことを一つの事業計画としてまとめたので、
それを伊藤さんに見ていただいて、一緒に進めていくことについてご相談したくて時間をもらいました。

結論から言うと、
「2027年9月までに、企業から復職後サポートを1社受注する」というゴールに向けて、
これから一緒に動いていただけないか、というお願いです。
```

## 2. 課題認識のすり合わせ(2分)

```
まず、これまでのヒアリングで見えてきたことを簡単に振り返らせてください。

復職された方は、通勤や業務そのものは緊張感で乗り切れることが多い一方、
帰宅後の夜間や土日祝に気力・体力が一気に落ちる、という声が多くありました。
「週末で回復しても月曜が怖い」が続くと、再休職のきっかけになりやすい。

支援員さんからも、「復職後1〜2か月で体調記録が途切れ、不調が出る。
面談は仕事の確認で精一杯」という声をいただいています。

つまり、支援が薄いのは平日夜間・土日祝。
ここを埋めることが、ヨルケアが役に立てる場所だと考えています。
```

## 3. 全体の道筋(3分)

```
今日ご相談したいのは、この空白を埋める仕組みを、
モニターから始めて、最終的には企業に売れるサービスに育てる計画です。
逆算するとこういう流れになります。

試運転(1か月・最少3名)
  → 振り返り・ブラッシュアップ
  → 無料モニター本編(5か月・21名)
  → エビデンスづくり
  → 個人向け月5,000円サービス
  → 企業から復職後3〜6か月サポートを受注(2027年9月まで)

今すぐ21名の本編に飛び込むのではなく、
まず最少3名の試運転で、進行やアプリの入力項目、安全対応の実際の動きを確認してから、
本編に進みます。ここは伊藤さんにも一緒に体験していただきたい部分です。

精神科医・安全責任者はすでに確保できているので、
その確保を待つ時間は不要です。空いた時間を試運転とその振り返りに充てられます。
```

## 4. なぜ企業受注をゴールにするか(2分)

```
個人向け月5,000円のサービスは、正直に言うと、満席の21名でも二人分の人件費は出ません。
副業として行う分には問題ないですが、ここで稼ぐ設計にはしていません。

個人有料版の役割は、「お金を払ってでも続けたい人がいる」という実績づくりです。
本命は、企業から復職後3〜6か月サポートを受注すること。
1人あたり月3〜5万円 × 3〜6か月で、同じ稼働でも個人向けの約7倍の単価になります。

企業に刺さるのは、症状スコアではなく「休まずに働き続けられたか」。
なので測る指標も、勤怠や仕事のパフォーマンス・活力を主役にして、
「効果があった」とは書かず、「参加者の変化」「完走率」までを参考データとして出す、
という誠実な見せ方にしています。
```

```
二つ目は、企業・事業所への営業です。
これは伊藤さんだけにお願いしたいわけではなく、私も一緒に動きます。
その上で、既存の6法人・137事業所との関係、そしてつながりのある支援機関へのパイプは、
伊藤さんが持っている一番の武器だと思っているので、
試運転と同じ時期(2026年9〜10月)から、
「検証を始めた」ことを伝える接点づくりを、私と伊藤さんそれぞれで始めたい、というお願いです。

私の方は、日曜の振り返り進行と、アプリ・アンケート・データまわりの運営に加えて、
この営業の接点づくりも一緒に担当します。

ここまでが今考えている役割分担ですが、
これは今日決め切るものではなく、これから一緒に固めていきたいところです。
```

## 6. 一緒に合意していきたいこと(2分)

```
実は今日決め切らなくていい、むしろ決め切ってはいけないと思っている項目が12個あります。
ゴールと期限、モニターの期間、役割分担と稼働の目安、
モニター期間中の報酬、有料化・企業受注後の収益配分、
精神科医・安全責任者の役割範囲、測る指標、参加者情報の扱い、
続ける・やめるの判断基準、そして判断する場をいつ持つか、などです。

ただ、これらを今日全部決めようとは思っていません。
特に報酬や収益配分は、まだ売り上げが立っていない今の段階で数字を詰めても、
かえって話がまとまりにくいと思うので、今日は保留にさせてください。

今日合意したいのはシンプルに一つだけです。
「まずは1か月、試運転をやってみましょう」ということです。
月末の定例ミーティングのような形は決めず、
報酬や収益配分などの細かい項目は、必要なタイミングで、そのつど相談させてください。
```

## 想定される質問への準備メモ

- **「本当に企業は買うのか?」** → 既存6法人・137事業所への就労定着支援(復職後6か月〜3年6か月)の枠に夜間・休日オプションとして乗せられる。再休職1件あたりの企業損失を企業自身に試算してもらう提案の仕方をする。厚労省の両立支援の努力義務化(2026年4月〜)は一次情報を確認のうえ根拠として使う。
- **「精神科医・安全対応は大丈夫か?」** → 精神科医・安全責任者は確保済み。5か月仕様の安全対応3段階・尺度使用条件はすでに整理済み(PHQ-9ではなくPHQ-8を採用するなど)。
- **「個人向けで稼げないなら意味があるのか?」** → 個人有料版は収益源ではなく実績づくり。本命は企業受注であることを正直に共有する(4節参照)。
- **「私の負担はどれくらい増えるのか?」** → 週の目安は21名時で運動+疲労回復が約2時間+営業活動。試運転(最少3名)はこれよりずっと小さい規模から始まる。
