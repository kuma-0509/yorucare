# ヨルケア 参加提案文 v2（復職後・就労中当事者向け）

作成日: 2026-07-12  
形式: 提案書（コピー用・貼り付け想定）  
対象: メンタル不調から復職（または就労継続）したあと、夜間・休日に心身の波が残っている当事者  
v1との違い: 「なぜ必要か／参加メリット／何が得られるか」を相手の問いの中心に据え、得られるものを3点で明示した  
踏まえた資料:
- VHA2026 エントリーシート（事業内容の正本）
- 日本うつ病学会「うつ病診療ガイドライン2025」（生活習慣・睡眠・復職まわりの背景根拠）
- ヨルケア5か月間オンラインプログラム確定仕様（時間・負担・データ・医療／緊急境界）

## 原稿

```
【提案】夜と休日の過ごし方を、5か月だけ一緒に変えてみてほしい
ヨルケアは、復職後に残りやすい心身の波へ、平日夜間・土日に届けるオンラインの運動・記録・振り返りです。
治療の代わりではありません。働き続けるための土台づくりとして、まずは記録アプリを試し、プログラム案内も受け取ってほしいです。

■ なぜ必要か（事実）
◎ 復職後に起きやすいこと
・通勤や業務は、緊張感で乗り越えられることが多い
・帰宅後の夜間や土日祝に、気力・体力が一気に落ちやすい
・「週末で回復しても、月曜日が怖い」が続くと、再休職のきっかけになりやすい
・ヒアリングでは、夜間のSNS（リベンジ夜更かし）で睡眠が削れる例があった
・月1回の面談までのあいだを、Excelで孤独に体調管理する例もあった
・支援員からは「復職後1〜2か月で体調記録が途切れ、不調が出る。面談は仕事の確認で精一杯」という声もある

◎ 空白が生まれる構造
・いまの支援の多くは、平日・日中前提で設計されている
・心身が乱れやすい平日夜間・土日祝に、相談やセルフケアの場がほぼない
・大事だと分かっていても、仕事終わりに一人で運動や記録を続けるのは難しい

■ 参加するメリット（得られること）
◎ 得られるもの（3つ）
1. 夜と休日に届く短い場
・火・木 各20分の夜の運動（カメラOFF・座ったまま可。両方必須ではない）
・日曜 合計45分の疲労回復と振り返り
・「一人で頑張る」より、「決まった短い時間がある」方が続きやすい、という設計
2. 同じ状況の仲間との振り返り
・原則3名。1人5分で「今週の状態／来週のセルフケア／維持したいこと」
・深い悩みを話す必要はない
・ヒアリングでは、同じ悩みを持つ人と話すと「自分だけじゃない」と感じられる、という声があった
3. 自分の状態を残せる記録
・アプリで気分・睡眠・服薬・しんどさのサインなどを1〜2分で記録（毎日義務ではない）
・振り返りや、主治医・支援者への相談材料にしやすい（本人が必要に応じて見せる形）
・アプリは端末内保存。運営者は原則閲覧しない。勤務先・支援機関へ自動共有しない

◎ 似た手段との違い
・YouTubeだけだと、今の自分に合う動きを選びにくく、一人だと続きにくい
・スマホ時間が増えて睡眠が短くなると、翌日の仕事に響きやすい
・ヨルケアは「短い決まった時間」「同じ状況の仲間」「記録で振り返れる」をセットにする

■ 試す根拠（背景。治癒の断定ではない）
◎ 事業側の事実
・復職後の夜間・休日の乱れと、「相談できる場所がない」課題を、当事者・支援員ヒアリングで確認している
・期間は5か月。募集は21名規模の実践研究。効果や症状改善は保証しない

◎ 診療ガイドラインが示す生活・睡眠の重要性
・日本うつ病学会「うつ病診療ガイドライン2025」では、生活習慣への配慮や睡眠・覚醒リズムの整えが、治療計画の基本に位置づけられている（CQ1-9、CQ1-4）
・軽度の段階では、生活習慣の調整・休養・心理教育などの基礎的介入が根幹になりうると整理されている（CQ2-2）
・不眠はうつ病に多くみられ、就労世代では1週間を通した規則的な睡眠・覚醒の確認が重要とされる（CQ8-1）
・労働者のうつ病では、復職準備として生活リズムの安定や日常の自己管理が重視され、生活記録表が参考にされる例もある（トピックス5）
・ヨルケアはこれらの「生活リズム・睡眠・自己記録」を、夜間・休日のプログラムとアプリに落とした設計
・ガイドラインの推奨を、製品の治癒効果として主張しない

■ 今日お願いしたいこと
◎ 選択肢（2つ）
1. 今すぐ：https://yorucare.vercel.app を開き、「書く」で気分と睡眠（またはしんどさのサイン）だけ残す（1〜2分）
2. 次の案内：夜間・休日プログラム（運動・振り返り）の参加案内を受け取る
→推奨：1を今日やり、案内受け取りも一緒に申し込む（記録の習慣と、場への参加を分けずに始められる）

◎ 合わなければやめてよい
・1週間アプリだけ試して判断してもよい
・プログラムは強制ではない。体調・仕事の波に合わせて休んでよい
・欠席や記録中断だけで参加終了にはならない
・全部参加なら週約92〜99分、火または木のみなら週約72〜79分が目安

■ リスクと対策
・アプリは端末紛失やブラウザ削除で記録が消える可能性がある → 週1回のファイル保存を推奨
・症状が強い・危険を感じるときは、アプリやセッションではなく医療機関・相談窓口を優先する
・パイロット中のため、日程・機能は変わることがある → 大きな変更は事前に共有する

■ 位置づけ（必ず読んでほしいこと）
・ヨルケアは、就業者の自己記録・セルフケア支援であり、うつ病の診断・治療・処方判断を行う医療行為ではない
・医療・福祉の空白時間を埋める補完的な生活支援として使う
・症状の悪化・自傷念慮等がある場合は、医療機関への相談が必要である

事業内容の整理：株式会社mimococo「支援の空白を埋める〜復職後の夜間・休日オンラインケア〜」
（Vision Hacker Association 2026 エントリーシート記載内容に基づく）
医学的背景の参照：日本うつ病学会「うつ病診療ガイドライン2025」
※ヨルケア／本プログラムは診断・治療・処方を行うものではありません。
```
