PRO BONO WANTED

夜と休日のオンラインコミュニティを、
続く事業にするところを手伝ってください

ヨルケアは、メンタル不調から復職したあと「平日の夜と土日」に調子を崩しやすい人のためのオンラインセルフケアです。火・木 21:00 の運動20分、日曜 21:00 の疲労回復＋振り返り45分、1日1〜2分の記録アプリ。2026年9月〜2027年3月に21名規模で実践研究を始めます。プログラムの中身はできました。事業にする部分が、まだできていません。

GOAL 1
個人が 月5,000円 を払い続けてくれるコミュニティにする
GOAL 2
企業に 復職後数か月のリワーク支援 として導入してもらう
01立ち上げ

月5,000円の中身と根拠

困っていること

いまは無料の検証プログラムしかなく、有料版に何を入れるか、なぜ5,000円なのかを説明できない。無料参加者に「来月から有料です」とどう伝えるかも決まっていない。

助けてほしいこと
  • 個人プラン・法人プランの構成と価格表のたたき台
  • 継続率を入れた簡易収支モデル
  • 無料検証から有料への移行シナリオ

事業開発／会員制・サブスクの価格設計
ヘルスケア領域の経験があれば尚うれしい

月1回60分のオンライン壁打ち × 6か月＋チャット

02立ち上げ

企業への売り方

困っていること

人事・産業医・障害者雇用担当・健康経営、どこに持ち込めばよいか定まらない。1名あたり月額か枠売りかも、稟議に何が必要かも分からず、法人向けの資料が1枚もない。

助けてほしいこと
  • 誰の予算で買われるのか、決裁ルートの整理
  • 法人向け提案書1式のレビューまたは作成
  • 導入企業に聞くべきこと／可能ならパイロット1社の紹介

人事・労務／産業保健／EAP・健康経営／法人営業
企業側で休職・復職に関わった経験

月1回60分＋資料レビュー2〜3回

03募集

21名を集める導線

困っていること

集客は就労移行支援事業所とクリニックからの紹介頼みで、止まったら止まる。募集ページも申込フォームもない。「治る」「効果がある」とは言えない領域で、何をどう書けば届くか迷っている。

助けてほしいこと
  • 募集ページの構成と文面
  • 申込 → 面談 → 同意までの導線整理
  • 紹介元（事業所・クリニック）に置く1枚チラシ
  • note・SNSで続けられる発信の型

Webマーケティング／コピーライティング／デザイン
医療・福祉分野の発信経験があれば尚うれしい

9〜10月に集中して合計10時間ほど＋以降は月1回

04運営

増えても回る運営

困っていること

連絡・出欠・3名×7グループの毎週の組み替え・記録確認まで、週3時間すべて手作業。決済も会員管理も退会フローも未整備で、有料化して人数が増えると確実に回らない。

助けてほしいこと
  • 週次運営の手順書とテンプレート
  • 決済・会員管理・出欠集計のツール選定と初期構築
  • 入会時の案内と、続けてもらうための設計
  • コミュニティのガイドライン

コミュニティ運営／カスタマーサクセス／業務改善・ノーコード
Notion・Stripe などの構築経験

初期構築でまとまった時間＋開始後は月1回の改善
