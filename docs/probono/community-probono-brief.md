## 0. 前提（この依頼のゴール）

| 区分 | ゴール |
|------|--------|
| 個人（BtoC） | **月5,000円**を払い続けてもらえるオンラインコミュニティにする |
| 法人（BtoB） | **復職から数か月間のリワークサポートプログラム**として企業に導入してもらう |

エントリーシート上の現状は「無料の効果検証フェーズ（1年目売上0円）」「2年目に月額3,000〜5,000円×50名」。
つまり **今回のゴールは、書いてある計画より一段上（価格の上限側＋法人導入）を先に取りにいく** ということ。この差分を埋めるのがプロボノに助けてほしい範囲。

- 提供形態: オンライン。火・木 21:00〜21:20（夜の運動20分）／日 21:00〜21:45（疲労回復20分＋振り返り25分）
- プログラム期間: 5か月／募集定員21名／振り返りは原則3名×7グループ

- 検証ステージ: 課題検証中（当事者・支援員へのヒアリング済み）。実践研究はこれから
- 体制: 代表＋業務委託4名（アプリ・コミュニティ運営／運動指導／精神科医・産業医／論文執筆）
- 既存の接点: 就労移行支援事業所6法人137施設、連携クリニック、障害者雇用の担当者
- 実施予定: 2026年9月〜2027年3月（募集開始9〜10月、セッション開始11月、中間データ12月、集計1〜3月）

## 1. 困っていること（立ち上げ／募集／運営の順）

### A. 立ち上げ：値付けと商品設計 ―「月5,000円の根拠」がない

- いま無料で検証する前提のプログラムしかなく、**有料版がどういう商品なのか（何が含まれ、何が含まれないか）が決まっていない**。
- 月5,000円は「オンラインフィットネス」でも「ピアサポート」でも「体調管理アプリ」でもない値付けになる。**比較対象と、その中でどこに位置づけるかが自分たちで説明できない**。
- 無料で参加した21名に、5か月後どうやって「では来月から5,000円」と言うのか。移行の設計がない。
- 代表自身の自己認識として「戦略的に考えること」「長い時間軸で逆算すること」が苦手（エントリーシート記載）。ここは他者の頭を借りたい部分。

### B. 立ち上げ：法人（リワーク）への売り方が分からない

- 「企業の復職後数か月のリワークサポートとして使ってもらう」と言っているが、**誰に売るのかが定まっていない**（人事／産業保健スタッフ・産業医／障害者雇用担当／健康経営推進／EAP経由）。
- 導入の形も未定：1名あたり月額か、年間契約か、休職者数に応じた枠売りか。
- 稟議を通すために企業側が何を求めるか（費用対効果、個人情報の扱い、事故時の責任分界、産業医との関係）が分かっていない。
- 提案書も価格表もない。今あるのは当事者向けの説明資料のみ。

### C. 募集：21名を集める導線がない／その後も集め続けられない

- 集客は既存の紹介（就労移行支援事業所・連携クリニック・障害者雇用担当）頼み。**紹介が止まったら止まる**。
- 募集LP、申込フォーム、説明会の型がない。申込〜面談〜同意取得〜グループ編成のフローが頭の中にしかない。
- センシティブ領域のため表現に不安がある。「治る」「効果がある」とは言えない（医療・緊急支援ではない、効果を保証しないと明記する方針）。**言えない中で伝わるコピー**が必要。
- 紹介元（事業所・クリニック）に置いてもらう1枚チラシもない。

### D. 運営：手作業で、有料化・人数増に耐えられない

- 運営工数は週3時間想定（参加者連絡、出欠確認、オンライン会準備、記録確認、振り返り会準備、参加状況整理）。**すべて手作業・属人的**。
- 欠席時のグループ編成ルール（1名なら統合、統合して4名なら2名×2に分割）が毎週発生する。人数が増えるほど破綻する。
- 有料化に必要な**決済・会員管理・入退会フロー**が未整備。ツールも未選定（Zoom／Google Workspace までは決まっている）。
- **継続してもらう仕掛け**が手探り。夜21時・週2〜3回・5か月という負担のなかで、どうすれば「来月も払う」状態になるのかの設計がない。
- 安全管理（レベル1〜3の対応フロー、PHQ-9の自傷項目の扱い）を少人数でどう回すか。運用に落ちきっていない。

### E.（できれば）効果検証の客観性

- PHQ-9／UWES-9／WHO-HPQ／PSQI の指標は選定済み。ただし**研究設計の妥当性・データ解釈・発信方法**は自分たちだけでは担保しきれない。
- これは VHA のメンター・専門家でも一部カバーされる見込みのため、プロボノでは「あれば嬉しい」枠とする。

## 2. 助けてほしいこと（募集する4＋1ポジション）

「話し相手になってほしい」ではなく、**成果物と関わり方をこちらから提示する**。1人1テーマでよい。単発の壁打ちだけでも歓迎。

### ① 値付け・商品設計（マネタイズ設計）

| 項目 | 内容 |
|------|------|
| 期待する成果物 | 個人プラン（月5,000円）の構成表／法人プランの価格表の叩き台／継続率を織り込んだ簡易収支モデル（スプレッドシート）／無料検証→有料への移行シナリオ |
| 関わり方の目安 | 月1回60分のオンライン壁打ち×6か月＋チャットで随時 |
| 求めるバックグラウンド | 事業開発、サブスク／会員制サービスの価格設計、ヘルスケア・ウェルネス領域の事業経験 |

### ② 法人開拓（人事・産業保健への売り方）

| 項目 | 内容 |
|------|------|
| 期待する成果物 | 想定顧客と決裁ルートの整理（誰に・どの予算で）／法人向け提案書1式／導入企業に聞くべきヒアリング項目／可能ならパイロット候補1社の紹介 |
| 関わり方の目安 | 月1回60分＋提案書レビュー2〜3回 |
| 求めるバックグラウンド | 人事・労務、産業保健、EAP、健康経営、障害者雇用、法人向け営業 |

### ③ 募集の導線づくり（マーケ・コピー・デザイン）

| 項目 | 内容 |
|------|------|
| 期待する成果物 | 募集LPの構成案と文面／申込〜面談〜同意取得の導線整理／紹介元（事業所・クリニック）向け1枚チラシ／note・SNSの投稿の型／表現チェック（言い切れない領域の書き方） |
| 関わり方の目安 | 立ち上げ期（9〜10月）に集中して合計10時間程度＋以降は月1回 |
| 求めるバックグラウンド | Webマーケティング、コピーライティング、デザイン、広報。福祉・医療領域の発信経験があれば尚可 |

### ④ 運営オペレーションとツール（続く運営をつくる）

| 項目 | 内容 |
|------|------|
| 期待する成果物 | 週次運営の手順書とテンプレート（連絡・出欠・グループ編成）／ツール選定と初期構築（決済・会員管理・出欠集計の自動化）／オンボーディングと継続設計／コミュニティガイドライン |
| 関わり方の目安 | 初期構築でまとまった時間＋運用開始後は月1回の改善 |
| 求めるバックグラウンド | コミュニティマネジメント、カスタマーサクセス、業務改善、ノーコード（Notion／kintone／Stripe など） |

### ⑤（あれば）効果検証の設計・分析

| 項目 | 内容 |
|------|------|
| 期待する成果物 | 研究設計と指標のレビュー／集計・統計解析／結果レポートの構成 |
| 関わり方の目安 | 開始時・中間・終了時のスポット3回 |
| 求めるバックグラウンド | 公衆衛生、産業精神保健、インパクト評価、データ分析 |

## 3. 共通の条件（募集時に明記する）

- 期間: 2026年9月〜2027年3月（プログラム実施期間に合わせる）。以降の継続は相談。
- 場所: オンライン中心（Zoom／チャット）。対面は必須ではない。
- 参加単位: 1人1テーマでOK。単発の壁打ち1回だけでも歓迎。
- 守秘: NDA対応可。**参加者（当事者）の個人情報・記録には触れない範囲**で関わってもらう（アプリ記録は本人端末内に保存、運営者も原則閲覧しない設計）。
- 医療との境界: ヨルケアは医療・緊急支援サービスではない。診断・服薬助言・24時間対応は行わない。

## 4. スライド化するときの優先順位

1枚に載せるなら、**ゴール2つ → 困っていること4つ → 助けてほしいこと4つ → 関わり方の条件 → 連絡先** の順。
⑤（効果検証）は脚注扱いにして、主役は「立ち上げ・募集・運営」に寄せる。

## 5. 元資料で確認が必要だった点（スライドには載せない）

- 助成金内訳の「オンライン運動レッスン委託費」は本文が240,000円、小計が44,000円。合計1,013,000円は小計44,000円で計算が合うため、**240,000円が誤記**と思われる（2,200円×週1回×月4回×5か月＝44,000円）。提出前なら要修正。
- 収支計画は「月額3,000〜5,000円×50名」。今回のゴール（月5,000円）と幅があるため、①の値付け設計で確定させる。
- 連絡先・担当者名はスライド上でプレースホルダにしてある。募集前に埋めること。
