## ①「提案スキルをどう自分専用にするか」の方針

### 利用目的

配布された提案スキル（writing-proposals）を、**就労中のメンタル不調経験者に、ヨルケアへの参加を提案する文章を作るためのスキル**にチューニングする。

今回作りたいのは、企業向けの導入提案ではなく、本人に対して、

> 今までの夜や休日の過ごし方を少し変えて、
> 運動・記録・振り返り・仲間とのつながりを5か月間試してみませんか

と提案する文章。

そのため、単なるサービス紹介ではなく、**本人の生活を変える提案**として書く必要がある。

特に意識したいのは、以下の3点。

1. **結論を最初に言う**
   - ヨルケアは何か
   - 何に参加してほしいのか
   - なぜ今提案するのか

2. **相手の困りごとから入る**
   - セルフケアが大事なのは分かっている
   - でも仕事後や休日に一人で続けるのは難しい
   - 自分の状態を整理して主治医・支援者に伝えるのも大変

3. **やさしいが、曖昧にしない文体にする**
   - 押しつけない
   - でも「参加してほしい」という判断は明確にする
   - 治療ではなく、働き続けるための心身の土台づくりとして伝える

### 想定する相手

想定する相手は、**就労中のメンタル不調経験者**。

精神保健福祉手帳の有無、障害者雇用枠で働いているかどうかは問わない。

具体的には、次のような人。

- メンタル不調を経験したあと、現在は働いている
- 平日は仕事で何とか踏ん張れている
- でも、夜や休日に気力・体力が落ちやすい
- 睡眠や生活リズムが乱れやすい
- セルフケアが大事なのは分かっているが、習慣化が難しい
- 主治医、支援者、職場に最近の状態を整理して伝えるのが大変
- 同じような経験を持つ人とつながれる場所が少ない

ここでのポイントは、相手を「支援される人」としてだけ見ないこと。
**自分の生活を変えるかどうかを決める、意思決定者として扱う**。

配布スキル標準の「忙しい・せっかち・ズボラな意思決定者」像は、この相手には合わない。
「警戒心と不安が先に立つが、自分の生活は自分で決めたい本人」に置き換えるのが、最大のカスタマイズポイント。

### コンテキスト

ヨルケアは、働き続けるための心身の土台を、**運動・記録・振り返り・仲間とのつながり**で整える5か月間のオンラインプログラム。

プログラム内容は以下。

| 内容 | 詳細 |
| --- | --- |
| 火・木 21:00〜21:20 | 副交感神経を優位にするストレッチ |
| 日 21:00〜21:20 | 疲労回復のセルフマッサージ・ストレッチ |
| 日 21:25〜21:45 | 1週間の良かったこと、改善点、来週のネクストアクションを共有する振り返りの会 |
| アプリ記録 | 睡眠、心身の状態、セルフケアの記録を蓄積する |

VHA資料上では、ヨルケアは「平日夜間・土日祝日」に特化したオンライン運動・セルフケアプログラムとして設計されており、今後20名程度を対象に実践研究を行い、PHQ-9、UWES-9、WHO-HPQ、PSQIなどで効果検証する計画になっている。

今回の提案文では、ヨルケアを単なるアプリではなく、

> **夜と休日に、一人で崩れやすい時間を支えるオンラインプログラム**

として伝える。

あわせて、スキルに毎回渡す固定情報として、次も維持する。

- 文言の正: `src/lib/copy.ts`（「セルフケア記録」「しんどさのサイン」「できたこと」など画面の言葉に合わせ、技術用語・研究用語を本文に出さない）
- 根拠方針: 治療効果は売らない。運動・記録・振り返りの一般的な研究＋プログラム設計＋実践研究での検証、という3点セットで語る
- アプリ記録のプライバシー説明は「記録本文／共有の有無／匿名の利用計測」の3層で書き分ける（過剰断言をしない）

## ② AIに渡す模範回答

以下を、提案スキルに入れる**模範回答のたたき台**にする。

```
【提案】ヨルケアの5か月間オンラインプログラムに参加してほしいです

セルフケアが大事だと分かっていても、仕事のあとや休日に一人で続けるのは簡単ではありません。
平日は仕事で気を張れていても、夜になると疲れが一気に出たり、日曜日の夜に翌週のことを考えて不安になったりすることがあります。睡眠や気分が乱れても、「いつから」「何がきっかけで」「どれくらいしんどいのか」を後から整理して、主治医や支援者に伝えるのは意外と大変です。

そこで、ヨルケアの5か月間オンラインプログラムに参加してほしいです。

ヨルケアは、働き続けるための心身の土台を、運動・記録・振り返り・仲間とのつながりで整える5か月間のオンラインプログラムです。

内容は大きく4つです。

1つ目は、火曜と木曜の夜21:00〜21:20に行うストレッチです。
仕事後の緊張をゆるめ、眠る準備に入りやすくすることを目指します。

2つ目は、日曜21:00〜21:20の疲労回復セッションです。
セルフマッサージやストレッチで、1週間の疲れをリセットし、翌週に向かう準備をします。

3つ目は、日曜21:25〜21:45の振り返りの会です。
今週よかったこと、少ししんどかったこと、来週試したいことを、同じような経験を持つ人たちと共有します。無理に深い話をする場ではありません。自分だけでは気づきにくい変化を、仲間と一緒に見つける時間です。

4つ目は、アプリでの記録です。
睡眠、気分、セルフケア、しんどさのサインなどを短く残します。記録があることで、自分の状態を客観視しやすくなり、主治医や支援者に最近の状態を伝えるときの材料にもなります。

このプログラムは、治療の代わりではありません。
ただ、働き続けるうえで大切な「睡眠」「回復」「振り返り」「人とのつながり」を、夜と休日の時間に整えるための仕組みです。

メンタル不調を経験した人にとって、セルフケアは大切です。
でも、それを一人で続けるのは難しい。だからヨルケアでは、運動・記録・振り返りをセットにし、さらに同じような経験を持つ人とつながれる形にしています。

5か月間、火曜・木曜・日曜の夜のセッション、日曜の振り返り、アプリ記録まで含めて参加してほしいです。
大きく生活を変える提案なので、不安があるのは自然です。体調や予定の波があることも前提にしながら、まずは一緒に続けられる形を探していきたいです。

ヨルケアを通じて、しんどさを一人で抱える夜を、少しでも整えられる時間に変えていきたいです。
働き続けるための心身の土台をつくる5か月間として、ぜひ参加を検討してください。
```

この模範回答がスキルに教えていること:

- 冒頭はサービス説明ではなく、相手の生活実感（夜・休日・日曜の夜の不安）への共感から入る
- 「治療の代わりではない」を必ず入れて、期待値の誤解を防ぐ
- 運動・記録・振り返り・仲間の4要素を分けて説明し、単なるアプリや運動会に見せない
- やさしい文体のまま、最後は「参加を検討してください」と行動を言い切る
- 不安があるのは自然、と相手の迷いを先に肯定する（小さく・可逆にする原則の応用）

## ③ スキルを動かしてみた結果と、次に直したい点

### 出てきた文章（チューニング前）

配布スキルをそのまま動かして最初に出てきたのは、**アプリの1週間無料トライアル案内**だった（`docs/proposal-presentation-employed-users.md`）。

良かった点は以下。

- ログイン不要、端末保存、自動共有なしなど、不安への説明が丁寧だった
- 「1日1〜2分」など、参加ハードルを下げる表現があった
- 記録のメリットやリスクも整理されていた
- 当事者に向けたやさしいトーンになっていた
- 結論ファースト＋「3つの不安への先回り」という骨格は、7〜8割そのまま使えた

一方で、レビュー（4つの専門視点）を通すと、今回の本来の提案とのズレも見つかった。

| 観点 | チューニング前 | 自分用に直したい方向 |
| --- | --- | --- |
| 提案の中心 | アプリを1週間試してほしい | 5か月間のオンラインプログラムに参加してほしい |
| 相手 | アプリ利用者 | 生活を変えるかどうかを決める当事者 |
| サービス定義 | セルフケア日記・記録ツール | 運動・記録・振り返り・仲間とのつながりで心身の土台を整えるプログラム |
| 困りごと | 記録できない、説明しづらい | セルフケアを一人で続ける難しさ、夜・休日に支援がないこと |
| 価値 | 記録で整理できる | 再不調を早めに防ぐ土台をつくる |
| 文体 | 機能説明が多い | やさしい共感から入り、最後は参加してほしいと言い切る |

さらに、動かしてみて初めて分かったスキル自体の弱点が2つあった。

- **事実と実装のズレを防げない**: 未実装の機能（相談窓口リンクなど）を、原稿が実装済みのように断言していた。スキルに「書いた事実を実態と突き合わせる工程」がない
- **プライバシーの過剰断言**: 「運営へ送信されない」と書いたが、匿名の利用計測は送信されていた。センシティブな領域向けのガードレールがない

### 自分専用スキルに入れたいルール

今後、SKILL.mdには以下のようなルールを追加したい。

1. **提案相手を「本人」として扱う**
   企業や支援者への提案ではなく、本人に対して生活を変える提案をする。
   相手を説得対象ではなく、**自分の生活を決める意思決定者**として扱う。

2. **冒頭は共感から入る**
   いきなりサービス説明をしない。最初に、相手の生活実感に触れる。
   例：「セルフケアが大事だと分かっていても、仕事のあとや休日に一人で続けるのは簡単ではありません。」

3. **サービス定義を必ず入れる**
   ヨルケアの定義は以下で固定する。
   「ヨルケアは、働き続けるための心身の土台を、運動・記録・振り返り・仲間とのつながりで整える5か月間のオンラインプログラムです。」

4. **運動・記録・振り返り・仲間の4要素を分けて説明する**
   単なる「アプリ」や「運動会」に見えないようにする。
   - 運動：睡眠・回復・生活リズムを整える
   - 記録：自分の状態を客観視し、主治医・支援者に伝えやすくする
   - 振り返り：良かったこと、改善点、次の一歩を整理する
   - 仲間：自分だけではないと思えるつながりを作る

5. **治療ではないことを明記する**
   誤解を避けるため、必ず以下のニュアンスを入れる。
   「ヨルケアは治療の代わりではありません。働き続けるための心身の土台を整えるセルフケアプログラムです。」

6. **最後は参加依頼で終える**
   やさしく書くが、結論をぼかさない。
   「5か月間のプログラムとして、ぜひ参加を検討してください。」のように行動を明確にする。

7. **事実・プライバシーのガードレール**（前回の失敗からの追加）
   - 機能・仕様を断言する文は、出力前に実装状況（DEVELOPMENT_BOARD.md、README）と突き合わせる
   - 「見られない・送られない」系の文は、記録本文／共有の有無／匿名の利用計測の3層に分解してから書く

### 次に直したい点

#### 1. 不安への答えを整理したい

参加者は、5か月間と聞くと不安になる可能性がある。特に想定される不安は以下。

- 5か月も続けられるか
- 体調が悪い日に参加できなかったらどうなるか
- グループで話すのがしんどくないか
- 記録を誰かに見られないか
- 運動が苦手でも大丈夫か
- 仕事後の夜に参加する気力があるか

次は、この中で**どの不安に一番先回りするか**を決めたい。

#### 2. エビデンスの入れ方を調整したい

運動、記録、振り返りにはそれぞれエビデンスがある。
ただし、当事者向けの提案文で研究の話を長く入れすぎると、読みにくくなる。

そのため、次は以下のバランスを調整したい。

- 本文では分かりやすく短く伝える
- 必要に応じて補足資料で研究根拠を示す
- 「運動はメンタルヘルスに良い」だけでなく、「だからヨルケアでは夜に短時間で行う」と設計に接続する

#### 3. 参加条件の言い方を磨きたい

現時点では、
「5か月間、火曜・木曜・日曜の運動、日曜の振り返り、アプリ記録まで含めて参加してほしい」としている。

ただし、実際の提案では、相手に負担感を与えすぎない言い方が必要。

今後は、

- どこまでを必須にするか
- 欠席や体調不良をどう扱うか
- 「完璧に参加」ではなく「続けること」をどう表現するか

を整理したい。

## 発表での一言まとめ

今回のチューニングで一番変えたのは、提案文を**アプリの無料体験案内**から、**就労中のメンタル不調経験者に生活の変化を提案する文章**に変えた点です。

ヨルケアは、単なる記録アプリではなく、
**働き続けるための心身の土台を、運動・記録・振り返り・仲間とのつながりで整える5か月間のオンラインプログラム**として伝える方針にしました。

汎用スキルは「構造」をくれるが、「事実の正しさ」と「相手に合う声」はくれない。
自分専用化とは、テンプレートの書き換えではなく、サービスの定義・相手の不安・文体の正という自分のコンテキストを、スキルが毎回参照する形で固定することだった。
