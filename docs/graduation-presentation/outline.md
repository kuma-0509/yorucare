# 卒業制作 発表（6分）— 決定した構成

**決定:** パターンA「29日間」型とパターンB「3つの条件」型の混成。比較検討は `outline-candidates.md`。
**デモ動画:** 全編46.56秒をそのまま流し、**上からナレーションを入れる**（無音のまま見せない）。原稿は `script.md`。

## なぜ混ぜたか

A のループ図は「詰まりが2か所ある」という**構造**を見せる。B の3つの条件は、その詰まりが**発表者の見立てではなく本人の言葉である**ことを見せる。混ぜると、3枚目で構造を示し、4枚目でその根拠を当事者の口から出す、という順序になり、片方だけより強い。

そのぶん時間を食うので、A から「先に引いた4本の線」の独立スライドを落とし（デモの受けで1文だけ言う）、B から「工夫：AIに書かせず選ばせる」を落とした。
