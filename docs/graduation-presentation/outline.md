# 卒業制作 発表（6分）— 決定した構成

**決定:** パターンA「29日間」型とパターンB「3つの条件」型の混成。比較検討は `outline-candidates.md`。
**改訂（2回目）:** 「なぜ記録が必要なのか」「なぜヨルケアがよいのか」の2つに答える章を足した。詳細は下の「改訂で直したこと」。
**デモ動画:** 全編46.56秒をそのまま流し、**上からナレーションを入れる**（無音のまま見せない）。原稿は `script.md`。

## 改訂で直したこと

初稿は「記録が続かない」から話が始まっていて、**そもそもなぜ毎日記録する必要があるのか**を飛ばしていた。聞き手はそこを抱えたまま最後まで聞くことになる。あわせて「Excelでも紙の手帳でもいいのでは」にも答えていなかった。

| 疑問 | どこで答えるか | 答えの骨 |
| --- | --- | --- |
| なぜ記録が必要なのか | ③（新設・52秒） | 復職後も治療は続く → 薬を続けるか減らすかを決めるのは月1回の診察 → 主治医は「この1か月どうでしたか」と聞く → 本人は記憶で答える → **記憶はその日の体調に引きずられる** → 治療を決める材料が診察日の気分で変わる。だから記録は、自分のためだけでなく**主治医が判断するための材料** |
| なぜヨルケアがよいのか | ⑦（新設・60秒） | 紙やExcelで続く人はいる、と認めたうえで差分3つ。①1件が成立する条件がいちばん軽い（状態1つ）②**記録項目を主治医と相談して選べる**＝その人の治療方針に合った記録になる ③外に送る実装がない＝**外へ出た本文0件** |

**「29日」の役割が変わった。**初稿では「支援者は月1回しか会えない」という情感の話だったが、改訂版では「**残りの29日を知っている人は本人しかいない → だから記録が要る**」という論の土台になっている。ここが今回いちばん効く。

そのぶん、ループ図の独立スライドを畳み（③のなかで役割を果たす）、「作らないと決めた3つ」を⑨の1文へ圧縮した。
