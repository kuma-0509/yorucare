〔スライド3。ループ図を指しながら〕

なぜこうなるのか。働き続けるために本人がやっていることを並べると、こうなります。

毎日、自分の心と体の状態を把握して、セルフケアをして、必要なときに主治医や支援者に相談して、治療や服薬の調整を受けて、体調を保って、働く。

**条件2、会社のものだと土日は書けない。**〔押していたらこの段落ごと飛ばす〕ログインも会社の許可も要りません。自分の端末で開くだけです。

**条件3、見られないようにしたい。**記録は端末の外に出しません。これは、気をつけて運用します、ではなくて、**外に送る実装そのものを作っていません。**通信先を自分自身に限定してあります。

結果として、端末の外へ出た記録の本文は、**0件**です。

# 言ってはいけないこと（通し練習でも守る）

| NG | 正しく言うなら | なぜ |
| --- | --- | --- |
| 「AIが報告書を作ります」 | 「記録から週のまとめを組み立てて、コピーして渡せます」 | 本番で動いているのは定型ルールの週のまとめまで。期間の報告書はプレビュー段階。触られると食い違う |
| 「うつ病の人は約6%」 | 「**生涯に**うつ病を経験する割合は約6%」 | 現在の有病率と読まれる |
| 「記録は安全です」「絶対に漏れません」 | 「外に送る実装がありません」「外へ出た記録の本文は0件です」 | 断言ではなく、確かめられる事実で言う |
| 「夜間や休日のためのアプリ」 | 使わない | 別会社の別サービスの説明。ヨルケアは時間帯を限定していない |
| 「体調を判定します」「アドバイスします」 | 「診断も治療もしません」 | 先に引いた線 |
