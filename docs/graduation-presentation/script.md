〔スライド3。いちばんゆっくり話す章。焦らない〕

再発する可能性が約50%ということは、**復職したあとも治療が続く**ということです。薬を続けるのか、減らすのか。それを決めるのは、**月に1回の診察**です。

その診察で、主治医は必ずこう聞きます。**「この1か月、どうでしたか」**

〔ここで一拍置く〕

本人は、**記憶で**答えます。

ここが問題です。人の記憶は、**その日の体調に引きずられます。**診察の日にたまたま調子が良ければ、しんどい日が10日あった月でも「まあまあでした」になる。

つまり今は、**治療を決める材料が、診察の日の気分で変わってしまう。**

私たち支援者が会えるのも、月に1回の面談だけです。**残りの29日を知っている人は、本人しかいません。**

だから記録が要ります。記録は、自分のためだけのものではなくて、**主治医が判断するための材料**です。

# 言ってはいけないこと（通し練習でも守る）

| NG | 正しく言うなら | なぜ |
| --- | --- | --- |
| 「好きな項目を自由に作れます」 | 「用意した項目を、主治医と相談して**出し入れできます**」 | 実装は5項目（自分メンテ／くわしく書く／しんどさのサイン／できたこと／小さな目標）の表示・非表示。既定は全部OFF。任意の項目は作れない。※自分の言葉で登録できるのは「できること」の登録簿のほう |
| 「AIが報告書を作ります」 | 「記録から週のまとめを組み立てて、コピーして渡せます」 | 本番で動いているのは定型ルールの週のまとめまで。期間の報告書はプレビュー段階 |
| 「うつ病の人は約6%」 | 「**生涯に**うつ病を経験する割合は約6%」 | 現在の有病率と読まれる |
| 「記録は安全です」「絶対に漏れません」 | 「外に送る実装がありません」「外へ出た記録の本文は0件です」 | 断言ではなく、確かめられる事実で言う |
| 「再発の予兆が分かります」「悪化を検知します」 | 言わない | 診断・危機判定をしないと決めている。記録は材料であって、判定はしない |
| 「他のアプリはダメです」 | 「それで続いている方もいます。ヨルケアが違うのは3つです」 | ⑦は比較であって否定ではない。断定すると聞き手が引く |
| 「夜間や休日のためのアプリ」 | 使わない | 別会社の別サービスの説明。ヨルケアは時間帯を限定していない |

# 通し練習の手順

1. **1回目** — 時計を見ずに声に出して読む。読みにくい語を自分の口に合う言い方へ直す。特に③は**ゆっくり読めるか**を確かめる。
2. **2回目** — ストップウォッチで計測。章ごとのラップを `outline.md` の表と突き合わせる。
3. **3回目** — スライドを送りながら通す。動画は必ず実際に再生する（ナレーションが尺に合うかはここでしか分からない）。
4. **6分を超えたら** — ⑧の質感の描写（約20字）→ ⑤の条件②（約20字）→ ②の統計を2件へ、の順で削る。**③と⑦は削らない。**
5. **5分20秒を切ったら** — 削りすぎか、早口になっている。③の「本人は、記憶で答えます」の前後で、もう一拍ずつ置く。
