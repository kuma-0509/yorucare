# 発表スライド（HTML）

`index.html` をブラウザで開くだけで動く、9枚のスライドです。原稿は `../script.md`、構成は `../outline.md`。

## 操作

| キー | はたらき |
| --- | --- |
| `→` `←` / `PageDown` `PageUp` | 送る・戻す |
| `Home` `End` | 最初・最後へ |
| `F` | 全画面（本番はこれ） |
| `N` | **発表者ノート**の開閉。右に原稿と、その面の目安の時刻が出る |
| `T` | **計測**の開始・停止。6分を超えると赤くなる |
| `R` | 計測を0に戻す |
| `V` / `Space` | 6枚目の動画を再生・一時停止 |

スマートフォンでは左右のスワイプでも送れます。`index.html#3` のように番号を付けて開くと、その面から始まります。

## 通し練習のしかた

1. `index.html` を開いて `F` で全画面にする
2. `N` でノートを開く（左にスライド、右に原稿が並ぶ）
3. `T` を押して声に出して読み始める
4. 面を送るたび、右上の「この面の終わり」と時計を見比べる。**時計が目安より進んでいたら押している**
5. 最後まで行って **5:43 前後**なら予定どおり。6分を超えると時計が赤くなる

## 本番前に必ず確認すること

- **動画が再生できるか。** 6枚目で `V` を押して確かめる。会場のPCで開く場合は `media/` フォルダごと持っていく（`index.html` から相対で参照している）
- **ネットが無くても崩れないか。** 書体は Google Fonts から読むが、届かないときは端末の日本語書体へ落ちる。文字の大きさと配置は変わらないので、そのまま進めてよい
- **画面比。** 1280×720（16:9）の板を、画面の大きさに合わせて拡大している。4:3のプロジェクターでは上下に余白が出るだけで、切れることはない

## 直したいとき

- 原稿を直したら、`index.html` の各 `<section>` の中にある `.notes-src` も直す（ここがノートの中身になる）
- 秒数の目安は各 `<section>` の `data-end`（発表開始からの通算秒）。構成を変えたらここも直す
- 配色と書体は、提出物の図解（`docs/graduation-project-diagram/`）と同じものを使っている
