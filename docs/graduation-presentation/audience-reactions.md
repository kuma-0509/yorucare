# 聞き手の心の声（時系列）

**これは何か:** `script.md` の改訂版を、最初から最後まで聞いたときの、聞き手の頭の中を時系列で書き出したもの。**レビューではない。**良し悪しの判定ではなく、その瞬間に何を思うかだけを書いている。

**聞き手の設定:** 半年間一緒に走ってきたチームのメンバー。発表者の仕事の中身は知らない。営業、事務、エンジニア、自分で店をやっている人など、職種はばらばら。前の人の発表を聞いた直後で、少し疲れている。**そして、素直には頷かない。**

**初稿での反省:** 前回書いた心の声は、聞き手が親切すぎた。「なぜ記録が必要なのか」「なぜこのアプリなのか」という当然の疑問を、誰も口に出していなかった。今回はそこを疑う人として書く。

〔全部に答える時間はない。**聞かれたら答えられるようにしておく**、が正解の項目〕

| 疑問 | 出るタイミング | 質疑での答え方 |
| --- | --- | --- |
| 「主治医は、その記録を見てくれるの？」 | ⑦の直後 | 見てもらうところまでレビューで進んだ。実際の診察で使ってもらうのはこれから（⑨のSTEP 3）。**まだ確かめていない、と正直に言う** |
| 「端末が壊れたら記録は消えるの？」 | ⑦の「外に出ない」で | 消える。だからファイルに保存して復元できるようにしてある。クラウド保存はGate 3の判定待ち |
| 「診察って本当に3分なの？」 | ④で | 短時間の診察を指す一般的な言い方。**厳密に3分と決まっているわけではない**、と補足できるようにしておく |
| 「何人が使ってるの？」 | ⑨で | まだ実機テスト前。**使用者数はゼロに近い、と正直に言う。**数を盛らない |
| 「収益はどうするの？」 | 直後の雑談で | 決めていない。今はGate 1の判定が先、と答える |
