# .pptx 版のスライド（Google スライド用）

出力物: `../yorucare-graduation.pptx`（9枚・16:9・13.333×7.5インチ）
生成元: `build.js`（pptxgenjs）

## Google スライドで開く

Google スライドに独自のファイル形式はないので、`.pptx` を取り込む。

1. Google ドライブへ `yorucare-graduation.pptx` をアップロードする
2. そのファイルを右クリック →「アプリで開く」→「Google スライド」
3. 開いた画面で「ファイル」→「Google スライドとして保存」

これで編集できる Google スライドになる。取り込んだ時点で図形も表も文字も**すべて編集できる**（画像に焼いていない）。

## 書体

`Noto Sans JP` を指定してある。Google スライドの書体一覧にあるので、そのまま出る。
PowerPoint で開く場合、入っていなければ端末の日本語書体へ置き換わる。文字数に合わせて余白を取ってあるので、多少幅が変わってもはみ出さない。

## 動画について

**6枚目に動画は入っていない。** `.pptx` に埋めた動画は Google スライドへ取り込むときに落ちるため、実機の画面3枚（書く／これまで／ふりかえり）を並べた面にしてある。

動画を流したいときは、どちらかにする。

- `../media/demo.mp4` を別のウィンドウで開いて、この面で再生する
- Google ドライブへ `demo.mp4` を上げ、Google スライドの「挿入」→「動画」→「ドライブ」から6枚目へ置く

## 発表者ノート

9枚すべてに原稿が入っている。Google スライドでは下部のノート欄に出る。発表者ビューでそのまま読める。
強調は原稿と同じ箇所を【　】で囲ってある。

## 直すとき

`build.js` を直して、次を実行する。

```
npm install pptxgenjs
node build.js ../yorucare-graduation.pptx ../media
```

第2引数は画像の置き場所。省略するとリポジトリ内の絶対パスを見にいく。

## HTML 版との違い

`../slides/index.html` は本番で使う版で、計測とノートの開閉が付いている。
`.pptx` は、Google スライドで配る・共同編集する・PowerPoint で開くための版。
**内容は同じだが、6枚目だけ違う**（HTML は動画、pptx は画面3枚）。原稿を直したときは両方を直す。
