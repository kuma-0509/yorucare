## 5. 「ちゃっちい」を脱して洗練させるプロンプト

### なぜ安っぽく見えるのか（原因と処方箋）

| 原因 | 処方箋 |
| --- | --- |
| 要素が多い（月＋人＋星＋文字） | **モチーフは1つだけ**に絞る |
| 人物が中途半端に具象的（顔・指・服） | 幾何学図形（円・弧）だけで構成する |
| 線幅・余白がバラバラ | 線幅を全て同じにする（モノライン）／円弧の中心を揃える |
| 色数が多い・グラデが安っぽい | **2色まで**。グラデを禁止し、べた塗りにする |
| 主役が大きすぎて窮屈 | 余白を大きく取り、主役はキャンバスの6割程度に |

→ 洗練されて見えるロゴは、ほぼ例外なく「**要素が少なく・作図が几帳面で・余白が広い**」です。

### A. 洗練版プロンプト（まずはこれ）

```
ヨルケア（夜のオンラインセルフケアプログラム）のロゴアイコンを作ってください。
今の案は要素が多く、クリップアートのようで洗練されて見えません。
高級スパ、北欧デザイン、ミニマルなエディトリアルデザインのような、
静かで品のあるロゴにしてください。

【スタイル】
minimal geometric logo mark, monoline, flat vector, editorial, refined,
Scandinavian, premium wellness brand, high-end spa branding, timeless

【デザインの原則（厳守）】
・モチーフは1つだけ。要素の足し算をしない
・円と円弧だけで構成する。手描き風の揺らぎや装飾は使わない
・線を使う場合は全ての線幅を完全に均一にする（モノライン）
・グラデーション・影・光彩・立体表現は一切使わない。完全なフラットのべた塗り
・色は2色まで（下記の配色から選ぶ）
・余白を大きく取り、モチーフはキャンバスの60%程度の大きさに収める
・左右のバランスと重心を整え、幾何学的に正確に作図する
・顔・指・服など具象的なディテールは描かない

【配色】
・#3d7ab8（落ち着いた青）＋ #f8f9fb（生成りの白）を基本に
・差し色が必要なら #f5e6c8（灯りのクリーム）をごく少量だけ

【避けたいもの】
clipart, cartoon, childish, cute mascot, busy, cluttered, 3D, glossy,
drop shadow, gradient mesh, stock illustration, generic

【出力条件】
・正方形（1:1）、1024×1024px
・LINEで丸くトリミングされるため、モチーフは中央に配置し周囲の余白を十分にとる
・文字（ロゴタイプ）は入れない
```

### C. さらに詰めるためのひとこと

- `要素をもう1つ減らしてください。引き算で洗練させてください。`
- `モチーフを10%小さくして、周囲の余白を広げてください。`
- `円弧の中心と半径を揃えて、幾何学的に正確に作図し直してください。`
- `色を#3d7ab8の1色だけにして、白背景のシングルカラーのロゴにしてください。`
- `ロゴの作図グリッド（補助線つき）も一緒に見せてください。`
- `40px・120px・512px の3サイズで並べたプレビューを出してください。`

### D. 仕上げのコツ

- 生成AIの出力は線がわずかに歪みます。**気に入った形が決まったら、Canva や Figma、
  Illustrator で「円と弧」を使って引き直す**と、一気にプロっぽくなります。
- 文字を添える場合、和文は「游ゴシック Medium」「Noto Sans JP Light」など細めの
  ゴシックを、**字間を広めに（トラッキング +100 程度）**取ると上品に見えます。
