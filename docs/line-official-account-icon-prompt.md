## 0. 先に押さえる仕様（LINE公式アカウントのアイコン）

| 項目 | 内容 |
| --- | --- |
| サイズ | 正方形・640×640px 以上（1:1） |
| 形式 | PNG または JPG、3MB以内 |
| 表示 | **丸く切り抜かれて表示される**ので、端ギリギリに絵や文字を置かない |
| 表示サイズ | トーク一覧では直径40px程度。**小さくても何か分かる**ことが最優先 |

→ 生成時は「正方形・中央に主役・周囲に余白・文字は入れない（or 最小限）」が鉄則です。

## 2. 生成後に使う「調整のひとこと」集

そのまま追加で送れば直してくれます。

- `2番の案をベースに、月をもう少し太く大きくして、星を3つに減らしてください。`
- `背景をもっと濃い夜の青にして、モチーフを生成り色に反転させてください。`
- `もっとシンプルに。要素を2つまで減らして、線を太くしてください。`
- `丸くトリミングされる前提で、周囲の余白を1.5倍に広げてください。`
- `40px に縮小した見え方のプレビューも一緒に出してください。`
- `同じデザインで、背景ありパターンと背景なし（単色塗り）パターンの2種類を出してください。`
