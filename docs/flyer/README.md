# ヨルケア 1か月モニター募集チラシ（A4両面）

既存チラシのデザイン刷新版。カフェ募集チラシの「型」（外周の余白ライン／写真＋カーブ切り抜き／
特大1語／ラベル＋値の表／ピル型タグ／濃色の連絡先帯／3色のみ）をヨルケアの内容に適用したもの。

## ファイル

| パス | 中身 |
| --- | --- |
| `index.html` | 版面そのもの。**修正はこのファイルだけを触る** |
| `yorucare-monitor-a4.pdf` | 入稿用PDF（A4 210×297mm・2ページ・フォント埋め込み済み） |
| `build.py` | HTML → PDF を書き出すスクリプト（版面のはみ出し検査つき） |
| `assets/` | 写真とQRコード |
| `fonts/` | Noto Sans JP / Noto Serif JP を本文で使う文字だけに絞ったもの（計約380KB） |

`fonts/` を同梱しているので、ネット接続がなくても、どのPCで開いても同じ字形で印刷できる。

## 直しかた

1. `index.html` をエディタで開いて文言や数値を直す
2. Chrome で `index.html` を開く
3. 「印刷 → 送信先：PDFに保存 → 用紙サイズ A4 → 余白：なし → 背景のグラフィック：ON」

スクリプトで出す場合：

```bash
pip install playwright pypdf && playwright install chromium
python3 docs/flyer/build.py            # docs/flyer/yorucare-monitor-a4.pdf を更新
```

最後に `版面はみ出し: なし` と出れば、文字が枠から出ていない。

## 決めごと

- **色は3色だけ** — 濃紺 `#1B2A41` ／ 白 `#FFFFFF` ／ グレー（`#EDECE8` `#DEDCD6` `#6E737B` `#D7D6D1`）。
  強調は色ではなく「文字の大きさと太さ」だけでつける。アクセント色は足さない。
- **本文は10.5pt以上**。9ptを使っているのは、両面の帯にある「主催／お問い合わせ／免責」の
  クレジット行だけ（元データは約7.5pt）。
- 書体は見出し＝Noto Sans JP 900、本文＝同 400/500、欧文ロゴのみ Noto Serif JP。
- QRコードは元PDFに入っていた画像をそのまま流用（`https://line.me/R/ti/p/@615ixfwt`）。作り直していない。
