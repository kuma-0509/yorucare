# スライドの作り直し方

`docs/ヨルケア事業化プラン_伊藤さん_20260905.pptx` を生成しているスクリプトです。

PowerPoint で直接編集してもかまいません。ただし「言い回しを全体で揃えたい」
「1枚のつくりを基準に残りを揃えたい」ときは、こちらを直して出し直すほうが、
次の資料にもそのまま効きます。

```bash
npm install pptxgenjs
node ito-business-plan.js ../ヨルケア事業化プラン_伊藤さん_20260905.pptx
```

完成品の `.pptx` は Git で追跡しています（`.gitignore` に `!/docs/*.pptx` の例外あり）。
スクリプトを直して出し直したら、`.pptx` も一緒にコミットしてください。

## 決めごと

- 元原稿: `docs/proposal-presentation-ito-business-plan.md`
- 骨子: `docs/骨子_伊藤さん事業化プラン_20260905.md`
- 差し色のゴールドは「今日お願いする一点」にだけ使う（それ以外はネイビー・グレー）
- 見出しは全スライドで同じ位置（Q＝問いを小さく、A＝答えを大きく）
- フォントは Meiryo。Mac で開く場合は「Hiragino Sans」等に置き換えてください
