# 1か月試運転プログラム アンケート設問集

作成日: 2026-09-12
更新日: 2026-09-12
目的: サービスとしての満足度を測る。あわせて、体調・メンタルの実感の変化とその理由、睡眠・生活リズムの変化、プログラム・アプリ・運営への評価を集める。
前提資料: `docs/evidence/yorucare-5month-program-spec.md`（確定仕様）

---

## 0. 設計の考え方（先に決めておくこと）

1. **「良くなったか」を終了時だけ聞かない。** 思い出して答えると印象に引っ張られる。睡眠・生活リズム・状態の設問は**参加前と終了時にまったく同じ文言**で聞き、点数の動きで見る。
2. **点数の直後に「その点数にした理由」を置く。** 理由を最後にまとめると、どの点数の話か分からなくなる。
3. **「睡眠が良くなった」で止めない。** 寝つき・長さ・途中で起きる回数・朝の回復感・就寝時刻の安定を**分けて聞く**。どれが変わったのかを1問で切り分ける設問（SL10）を必ず入れる。
4. **プログラム以外の理由も必ず選択肢に入れる。** 仕事の繁忙・通院・季節でも体調は変わる。入れないと効果を大きく見せてしまう。
5. **1か月・少人数・比較群なしの試運転は「効果を証明する調査」ではない。** 集めるのは満足度と改善点。報告書にもそう書く。
6. **自傷や死にたい気持ちを直接尋ねる項目（PHQ-9 第9問など）は使わない。** 確定仕様 9節のとおり、確認担当者・期限・連絡手順を決められない場合は使わない。
7. **氏名は取らず参加者IDで管理する。** 出席回数・記録日数はアンケートで聞かず運営記録から取る（本人に数えさせない）。

### 回答形式の統一

- 原則すべて**5段階**（1 まったくそう思わない / 2 あまり / 3 どちらとも / 4 ややそう思う / 5 とてもそう思う）。
- 0〜10点は「人に勧めたいか」の1問だけ。
- **★が付いた設問だけ必須**。他は任意にして答えやすさを優先する。時間が長くなりすぎる場合は★以外から削る。

### 全アンケートの冒頭に入れる文

> この回答はリアルタイムには確認されません。急ぎの相談や支援が必要なときは、このアンケートを使わず、医療機関や緊急サービスへ直接ご連絡ください。

## 集計のしかた（報告時の約束）

- 割合を書くときは必ず母数（何人中何人か）を添える。人数が少ないので割合だけを大きく出さない。
- S1〜S7、SL1〜SL6、LR1〜LR5は事前・事後の値とその差を出す。**統計的な有意差の主張はしない。**
- 睡眠は「良くなった」とまとめず、SL11（一番変わったもの）の内訳を必ず出す。
- Q8でプログラム以外の理由を挙げた人数を必ず併記する。
- 自由記述は良い評価だけを抜き出さない。否定的な意見は件数とともにそのまま載せる。
- 出席回数・記録日数は運営記録から取り、満足度との関係を見る。
- 報告書に「症状が改善する」「効果がある」とは書かない。書けるのは**参加者の主観的な実感と満足度**まで。
