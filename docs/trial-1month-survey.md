# 1か月試運転プログラム アンケート設計

作成日: 2026-09-12
目的: サービスとしての満足度を測る。あわせて、参加者の体調・メンタルの実感の変化と、その理由を集める。
前提資料: `docs/evidence/yorucare-5month-program-spec.md`（確定仕様）

---

## 0. 先に決めておくこと（設計の考え方）

1. **「良くなったか」だけを終了時に聞かない。** 終わってから思い出して答えると、印象に引っ張られる。同じ質問を**参加前と終了時の2回**聞いて、点数の動きで見る。
2. **点数の直後に「その点数にした理由」を置く。** 理由を最後にまとめて聞くと、どの点数の話か分からなくなる。
3. **プログラム以外の理由も選べるようにする。** 仕事の繁忙、通院、季節でも体調は変わる。これを選択肢に入れないと、効果を大きく見せてしまう。
4. **1か月・少人数の試運転は「効果を証明する調査」ではない。** 比較する集団がないので「良くなった＝プログラムのおかげ」とは言えない。目的は満足度と改善点を集めること。報告書にもそう書く。
5. **自傷や死にたい気持ちを直接尋ねる項目（PHQ-9の第9問など）は、試運転では使わない。** 確定仕様 9節のとおり、確認担当者・確認期限・連絡手順を決められない場合は使わない。
6. **氏名は取らず参加者IDで管理する。** 出席回数・記録日数はアンケートで聞かず、運営記録とアプリ側の匿名集計から取る（本人に数えさせない）。

### 全アンケートの冒頭に入れる文

> この回答はリアルタイムには確認されません。急ぎの相談や支援が必要なときは、このアンケートを使わず、医療機関や緊急サービスへ直接ご連絡ください。

### 回答形式の統一

- 原則すべて**5段階**。（例：1 まったくそう思わない / 2 あまり / 3 どちらとも / 4 ややそう思う / 5 とてもそう思う）
- 0〜10点を使うのは「人に勧めたいか」の1問だけ。
- 必須にするのは「総合満足度」「体調・メンタルの変化」とその**理由の自由記述**だけ。他は任意にして、答えやすさを優先する。

### 実施タイミングと所要時間

| 時期 | 内容 | 目安 |
|------|------|------|
| 参加前 | 事前アンケート（A〜C） | 8分 |
| 毎週日曜のセッション後 | 週次3問 | 30秒 |
| 1か月終了時 | 事後アンケート（1〜3） | 12分 |
| 途中でやめたとき | 辞退時アンケート | 3分 |

## 1. 事前アンケート（参加前・約8分）

### A. 基本情報

- A1 参加者ID
- A2 年代（20代／30代／40代／50代／60代以上）
- A3 現在の働き方（週5日／週4日／週3日以下／休職中／その他）
- A4 参加のきっかけ（複数選択：眠れない／朝つらい／疲れが取れない／気分の落ち込み／仕事を続ける自信がない／セルフケアの習慣をつけたい／その他）
- A5 このプログラムに期待すること（自由記述・1問）

### B. いまの状態（**事後アンケートとまったく同じ7問**）

いずれも「**この1週間について**」5段階で聞く。

| 番号 | 質問 |
|------|------|
| S1 | 布団に入ってから、寝つきはよかった |
| S2 | 夜中に目が覚めずに眠れた |
| S3 | 朝起きたとき、疲れが取れている感じがした |
| S4 | 日中、体が重くだるい感じがあった（※逆向きの質問） |
| S5 | 気分が落ち込むことがあった（※逆向きの質問） |
| S6 | 仕事に向かう気力があった |
| S7 | しんどくなったとき、自分で対処できそうだと思えた |

※ S4・S5は「あった方が悪い」質問。集計時に向きをそろえる。

### C. 困りごと

- C1 いま一番困っていること（自由記述・1問）

## 2. 週次アンケート（毎週日曜のセッション後・3問・30秒）

1か月は短く、事前と事後の2点だけでは途中の変化が見えない。負担にならない3問だけ置く。

- W1 今週の体調・気分は全体としてどうでしたか（5段階）
- W2 今週のプログラムは自分の役に立ちましたか（5段階）
- W3 負担に感じたこと・やりにくかったことがあれば（自由記述・任意）

---

## 3. 事後アンケート（1か月終了時・約12分）

### ブロック1：満足度（今回の主目的）

| 番号 | 質問 | 形式 |
|------|------|------|
| Q1 | プログラム全体にどのくらい満足しましたか | 5段階 |
| Q1-1 | **その点数にした理由** | 自由記述（必須） |
| Q2 | 内容ごとの満足度：①火・木の夜の運動 ②日曜の疲労回復 ③日曜の振り返り ④アプリの記録 | 各5段階 |
| Q3 | 一番役に立ったのはどれですか | ①〜④＋「特にない」から1つ |
| Q3-1 | それはなぜですか | 自由記述 |
| Q4 | 一番負担だったのはどれですか | ①〜④＋「特にない」から1つ |
| Q4-1 | それはなぜですか | 自由記述 |
| Q5 | このあとも続けたいと思いますか | 5段階 |
| Q5-1 | その理由 | 自由記述 |
| Q6 | 同じ立場の人に勧めたいと思いますか | 0〜10点 |
| Q6-1 | その点数にした理由 | 自由記述 |
| Q7 | 時間・回数はちょうどよかったですか：①1回の長さ ②週の回数 ③曜日・時間帯 ④アプリ記録の項目数 | 各「多い／ちょうどよい／少ない」 |

### ブロック2：体調・メンタルの変化と、その理由（ご要望の2問を分解したもの）

- **Q8　事前アンケートのS1〜S7とまったく同じ7問**（点数の動きで見る）

- Q9　参加する前と比べて、**体調**は全体としてどうなりましたか
  - 5段階（とても良くなった／少し良くなった／変わらない／少し悪くなった／とても悪くなった）
- Q10　参加する前と比べて、**気持ちの面（メンタル）**は全体としてどうなりましたか
  - 同じ5段階

- **Q11　Q9・Q10でそう答えた理由（複数選択）**
  - 良くなった側の選択肢
    - 夜の過ごし方が決まって、寝る前の流れができた
    - 寝る前にスマホを見る時間が減った
    - 体のこわばりがほぐれた／呼吸が落ち着いた
    - 自分の状態に気づけるようになった
    - 週に1回、人に話す機会があった
    - 同じ立場の人がいると分かって安心した
    - 次に試すセルフケアが決まった
    - 記録をつけること自体が続いた
  - 変わらない・悪くなった側の選択肢
    - 参加する時間の確保が負担だった
    - 記録を書くのが負担だった
    - 内容が自分に合わなかった
    - 生活や仕事が忙しく、実践できなかった
    - もともと大きく困っていなかった
    - 1か月では短すぎた
  - プログラム以外の理由（**必ず入れる**）
    - 仕事の状況が変わった（繁忙・異動・休職など）
    - 通院や薬の内容が変わった
    - 季節・天候・家庭の事情など
    - その他

- **Q11-1　上のほかに、そう感じた理由を自由に書いてください（必須）**
- Q12　変化を感じたのはいつ頃ですか（1週目／2週目／3週目／4週目／特に感じなかった）

### ブロック3：改善点・安全

| 番号 | 質問 | 形式 |
|------|------|------|
| Q13 | 参加できなかった回がある場合、その理由 | 複数選択（仕事／体調／予定／気が進まなかった／時間を忘れた／接続がうまくいかなかった／その他） |
| Q14 | アプリに記録できなかった日がある場合、その理由 | 複数選択（忘れた／書く気力がなかった／書くことがなかった／操作が分かりにくい／書いた内容を見られるのが不安／その他） |
| Q15 | 困ったこと・嫌だったこと・やめた方がよいと思ったこと | 自由記述 |
| Q16 | 改善してほしいこと、追加してほしいこと | 自由記述 |
| Q17 | （検証目的に含める場合のみ）有料なら月いくらまでなら続けられますか | 価格帯の選択＋「有料なら続けない」 |

## 4. 途中辞退時アンケート（3分）

- E1 やめた理由（複数選択：体調／仕事の都合／時間が合わない／内容が合わない／負担が大きい／効果を感じない／その他）
- E2 続けられるとしたら、何があればよかったですか（自由記述）
- E3 やめた理由に体調の悪化は含まれますか（はい／いいえ／答えたくない）
  - ※「はい」は安全確認の対象。確定仕様 8節の対応に従い、確認担当者と期限をあらかじめ決めておく。

---

## 5. 集計のしかた（報告時の約束）

- 割合で書くときは必ず母数（何人中何人か）を添える。人数が少ないので、割合だけを大きく出さない。
- S1〜S7は事前・事後の点数と、その差を出す。**統計的な有意差の主張はしない。**
- Q11でプログラム以外の理由を挙げた人がいる場合は、その人数を必ず併記する。
- 自由記述は、良い評価だけを抜き出さない。否定的な意見は件数とともにそのまま載せる。
- 出席回数・記録日数はアンケートの回答ではなく運営記録から取り、満足度との関係を見る。
- 報告書に「症状が改善する」「効果がある」とは書かない（医学的効能の主張はしない）。書けるのは「参加者の主観的な実感」と「満足度」まで。

## 6. 実施チェックリスト

- [ ] 事前アンケートを参加前（初回セッション前）に完了させる
- [ ] 参加者IDと氏名の対応表は、アンケート回答とは別の場所に保存する
- [ ] 全アンケートの冒頭に「リアルタイム確認しない」旨を表示する
- [ ] 希死念慮を尋ねる項目を使っていないことを確認する
- [ ] 辞退時アンケートのE3が「はい」だったときの確認担当者・期限を事前に決める
- [ ] 事後アンケートの回収期限（終了後1週間以内など）を決める
