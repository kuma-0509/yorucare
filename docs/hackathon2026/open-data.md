# 利用オープンデータの整理（フォーム 4-1 用）

## 現状と方針

**ヨルケアは、2026-08-17 時点でオープンデータを1件も使っていません**（リポジトリ全文検索で該当0件）。
提出要件は「最低1つ以上のオープンデータが必要」なので、ここが唯一の欠落項目です。

そこで、**アプリの弱点をオープンデータで埋める**方向で選びました。
ヨルケアには全タブ共通の相談導線がありますが、`src/lib/consultation-resources.ts` を見るとおり、
現在つながる先は **119 / 110 / #いのちSOS / 厚労省の2サイト** の5件だけで、
**利用者が住む地域の窓口へは案内できていません**。ここを都のオープンデータで置き換えます。

> **重要（この文書の限界）**
> 作業環境から `catalog.data.metro.tokyo.lg.jp` `e-stat.go.jp` `data.go.jp` `mhlw.go.jp` へは
> ネットワークが遮断されており、**データセットの実在・タイトル・中身をこちらで確認できていません**。
> 下記URLは検索結果から拾った候補です。**提出前に必ずご自身でURLを開き、タイトルと更新時点を確認**してください。
> 確認できなかったものは提出に載せず、カタログを検索して置き換えてください。

## 数値の扱いについて

**確認できていないデータの数値を、資料にも提出文にも書きません。**
「夜間・休日に開いている窓口は◯件だけ」といった集計値をスライドに載せるのは、
実データを取り込んで計算したあとだけにします。それまでは、
資料は「相談導線を地域の窓口へ広げる」という**設計として**書きます。
