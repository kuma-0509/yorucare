```
ヨルケア
```

### 2-3. サービスの詳細

```
ヨルケアは、メンタル不調を経て働き続ける人が、夜と休日のセルフケアを1日1〜2分で残せるWEBアプリです。入口で「よい・ふつう・しんどい」の3段階を選ぶと、その選択に応じて質問が絞られるため、しんどい日ほど短く終わります。記録した状態から選べそうなセルフケア案を出す「自分メンテ」、1週間の状態を日数でまとめる「ふりかえり」、書けた日を数える「積み重ね」を備えます。記録は端末の中だけに保存し、主治医や支援者へ状態を伝える材料として本人が持ち出せます。どの画面からも相談窓口へ一手でつながります。
```

### 2-4. 着目した課題・背景

```
メンタル不調から復職し、いま働いている人が対象です。通勤や業務は緊張感で乗り越えられても、帰宅後の夜や土日祝に気力と体力が一気に落ちます。ところが支援は平日日中が前提で、支援面談は月1回程度。最も崩れやすい時間帯には、ほとんど何も届きません。当事者への聞き取りでは、夜のSNS閲覧が常態化して睡眠が削られる、会社には相談しにくく自作の表で孤独に体調管理をしている、という声がありました。支援員からは、復職後1〜2か月で記録が途切れ不調が出る、面談は仕事の確認で精一杯だと聞いています。「週末で回復させても月曜が怖い」が繰り返され、再休職の引き金になります。
```

### 2-5. 課題・背景の解決方法

```
支援が届かない夜と休日に、本人が一人でも続けられる記録の仕組みを置きます。3段階の入口で入力量を絞り、しんどい日でも1〜2分で終わる設計にして「続かない」に正面から対処します。記録は評価のためではなく自分を理解するためのものと位置づけ、書けなかった日を失敗として扱いません。中断しても減らない累計を先に見せ、戻ってきやすくします。溜まった記録は1週間ごとに日数でまとめられ、月1回の面談や診察で「最近どうですか」に答えるための材料になります。相談が必要なときは、本人の操作だけで公的な窓口へつながります。
```

## 3. 技術詳細

### 3-1. 技術選定の理由

```
Next.js（App Router）、TypeScript、Tailwind CSSで構築し、Vercelで配信しています。技術選定の軸は「本人が書いた記録を端末の外へ出さない」ことでした。そのためログインとサーバ保存をあえて作らず、記録はブラウザのlocalStorageに置き、Zodでスキーマ検証と版管理をしています。データ操作は一箇所へ集約し、将来API層へ差し替えられる境界だけ先に用意しました。継続率の検証に必要な匿名イベントのみ別経路でNeon Postgresへ保存し、端末IDは保存前に不可逆化しています。完了演出はReact Three Fiberで、外部アセットを使わず生成しています。
```

### 3-2. 生成AI等の活用方法

```
開発はClaude Codeで進め、設計判断と次回への引き継ぎを毎回リポジトリの文書に残す運用にしました。工夫したのは、記録を言語化する機能で生成AIに自由文を書かせないことです。数値はアプリが確定させ、文章の穴だけをアプリが用意した3つの候補から選ばせる穴埋め方式にしました。禁止語の一覧で事後に濾す方式は必ず取りこぼすことを実際に確かめ（「肺炎です。」が通過した）、その事実をテストとして残したうえで設計そのものを変えています。型にも自由文のフィールドを置いていないため、想定外の助言や診断が本人の画面へ出る経路がありません。
```
