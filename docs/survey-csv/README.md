# アンケートCSV（Googleフォーム作成用）

`docs/trial-1month-survey.md` の設問を、そのままフォームへ流し込める形にしたものです。

| ファイル | 中身 | 設問数 |
|---|---|---|
| `01_pre.csv` | 事前アンケート（参加前） | 15 |
| `02_weekly.csv` | 週次アンケート（毎週日曜） | 5 |
| `03_post.csv` | 事後アンケート（1か月終了時） | 80 |
| `04_withdrawal.csv` | 途中辞退時アンケート | 4 |

文字コードは UTF-8（BOM付き）です。Excel・Googleスプレッドシートのどちらでもそのまま開けます。

---

## 列の意味

| 列 | 内容 |
|---|---|
| `form` | どのアンケートか（事前／週次／事後／辞退時） |
| `section` | フォーム内のセクション名。変わるところでページを分ける |
| `qid` | 設問番号。`docs/trial-1month-survey.md` と対応する |
| `required` | `必須` と書いてあるものだけ必須にする。空欄は任意 |
| `question` | 設問文。**そのまま使う**（事前と事後で同じ文言にするため） |
| `type` | 回答形式（下表） |
| `options` | 選択肢。`|` 区切り |
| `rows` | グリッドの行（縦に並ぶ項目）。`|` 区切り |
| `note` | 運営向けのメモ。フォームの補足説明に入れてもよい |

### `type` の種類

| 値 | Googleフォームでの項目 |
|---|---|
| `説明` | フォーム冒頭の説明文（項目にはしない） |
| `記述` | 記述式（短文） |
| `段落` | 段落（長文） |
| `ラジオ` | ラジオボタン（1つ選択） |
| `チェックボックス` | チェックボックス（複数選択） |
| `グリッド` | 選択式グリッド（`rows` が行、`options` が列） |
| `目盛` | 均等目盛。`options` は `下限|上限|下限ラベル|上限ラベル` |

## Googleフォームの作り方

> **注意**：Googleフォームには「CSVを読み込んで設問を作る」機能がありません。
> スプレッドシート経由で Apps Script に作らせるのが一番確実です。

### 手順（1フォームあたり5分）

1. Googleスプレッドシートを新規作成する
2. **ファイル > インポート** で `01_pre.csv` を読み込む（「新しいシートを挿入する」を選ぶ）
3. **拡張機能 > Apps Script** を開く
4. `create-form.gs` の中身をすべて貼り付けて保存する
5. 上部の関数一覧で `buildFormFromActiveSheet` を選び、**実行**する
   - 初回だけ権限の承認を求められます（自分のGoogleアカウントのフォームを作るためです）
6. 実行ログに出る **編集URL** を開く

`02_weekly.csv` 以降も、シートを切り替えて 5 を実行するだけです（**実行前に、対象のシートを開いておく**のを忘れずに）。

### 作成後に手でやること

- [ ] 事後アンケートの Q6・Q7 に「Q1またはQ2で○○と答えた方へ」と補足を入れる（分岐は使わず、補足文で十分です）
- [ ] P17（価格）を使わない場合は削除する
- [ ] 回答の保存先スプレッドシートを、参加者名簿とは**別のファイル**にする
- [ ] メールアドレスを収集しない設定になっていることを確認する（スクリプトでOFFにしていますが念のため）
- [ ] 事前と事後で S・SL・LR の設問文が1文字も違わないことを見比べる
