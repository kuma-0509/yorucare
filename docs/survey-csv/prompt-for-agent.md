# エージェント（ChatGPT の Work / エージェントモードなど）に渡すプロンプト

CSVを添付したうえで、以下をそのまま貼り付けてください。
`【　】` の中だけ自分の状況に合わせて書き換えます。

---

## プロンプト1：Googleフォームを作らせる（メイン）

```
あなたはアンケート実装の担当者です。添付したCSVから、Googleフォームを4つ作ってください。

# 添付ファイル
- 01_pre.csv（事前アンケート）
- 02_weekly.csv（週次アンケート）
- 03_post.csv（事後アンケート）
- 04_withdrawal.csv（途中辞退時アンケート）

# CSVの読み方
1行目がヘッダーです。列の意味は次のとおりです。
- form: どのアンケートか
- section: フォーム内のセクション名。値が変わるところでページを分ける
- qid: 設問番号。設問文の先頭に「Q1. 」のように付ける
- required: 「必須」と書かれた行だけ必須にする。空欄は任意にする
- question: 設問文
- type: 回答形式
- options: 選択肢。半角の「|」区切り
- rows: グリッドの行。半角の「|」区切り
- note: 運営向けメモ。フォームの補足説明（ヘルプテキスト）に入れる

typeの対応は次のとおりです。
- 説明 → 項目にしない。フォーム全体の説明欄に入れる
- 記述 → 記述式（短文）
- 段落 → 段落（長文）
- ラジオ → ラジオボタン（1つ選択）
- チェックボックス → チェックボックス（複数選択）
- グリッド → 選択式グリッド。rowsが行、optionsが列
- 目盛 → 均等目盛。optionsは「下限|上限|下限ラベル|上限ラベル」の順

# 作り方
Googleフォームの画面を1問ずつ手で作るのではなく、Google Apps Script を使って自動生成してください。
手順:
1. Googleスプレッドシートを新規作成し、4つのCSVをそれぞれ別シートとして取り込む
2. 拡張機能 > Apps Script を開く
3. CSVの1行を1設問として読み、上の対応表どおりにフォーム項目を追加するスクリプトを書く
4. 4つのシートそれぞれに対して実行し、フォームを4つ作る
5. 各フォームの編集URLと回答URLを報告する

# 必ず守ること
1. 設問文と選択肢の文言を変えない。言い換え・要約・敬語の統一・誤字の修正もしない。
   事前アンケートと事後アンケートで同じ設問を比較するため、1文字でも違うと集計できなくなる。
2. 設問の順番を変えない。CSVの並び順どおりにする。
3. 設問を足さない。減らさない。
4. required列が「必須」の行だけ必須にする。それ以外を必須にしない。
5. メールアドレスの自動収集をOFFにする。氏名を尋ねる設問を追加しない。
6. 各フォームの説明欄（冒頭）に、type=説明 の行の文言をそのまま入れる。
7. ログイン必須・1人1回の制限はかけない。

# 完了したら報告してほしいこと
- 4つのフォームの編集URLと回答URL
- 各フォームの設問数（CSVの行数と一致しているか）
- 作成中にCSVの内容で判断に迷った箇所があれば、その一覧（勝手に直さず、質問として挙げる）
```

## プロンプト2：作ったフォームを点検させる

フォームができた後に、別のセッションで実行すると見落としを拾えます。

```
添付したCSVと、次のGoogleフォームを照合して、食い違いを一覧で出してください。
- 事前: 【URL】
- 週次: 【URL】
- 事後: 【URL】
- 辞退時: 【URL】

確認してほしい点:
1. 設問数がCSVの行数と一致しているか
2. 設問文がCSVと1文字も違わないか（違う箇所はCSV側とフォーム側を並べて示す）
3. 選択肢の文言と並び順がCSVと一致しているか
4. required列が「必須」の行だけが必須になっているか
5. メールアドレスの収集がOFFになっているか
6. 事前アンケートと事後アンケートで、qidが S1-S7 / SL1〜SL6 / LR1-LR4 / LR5 の設問文と選択肢が完全に同じか

直してよいか判断できない箇所は、勝手に直さず一覧に挙げてください。
```

## プロンプト3：回答が集まった後に集計させる（1か月後）

```
あなたは調査結果をまとめる担当者です。添付した回答データを集計して、報告書のたたき台を作ってください。

# 添付
- 事前アンケートの回答（スプレッドシート）
- 事後アンケートの回答（スプレッドシート）
- 週次アンケートの回答（スプレッドシート）
- 設問定義: 01_pre.csv / 03_post.csv

# やってほしいこと
1. 参加者IDで事前と事後を突き合わせる
2. S1〜S7、SL1〜SL6、LR1〜LR4、LR5 について、事前と事後の値と差を出す
3. Q1（体調）・Q2（メンタル）の回答分布を出す
4. SL11（睡眠で一番変わったもの）の内訳を出す
5. LR6（生活リズムの作りやすさ）の分布を出す
6. P1（総合満足度）、P15（継続意向）、P16（推奨意向）の分布を出す
7. 自由記述（Q10, P2, P12b, P13b, A10, O11）を、良い点・改善点・その他に分けて全文を並べる

# 集計と書き方のルール（必ず守る）
1. 割合を書くときは必ず母数を添える（例:「21人中14人（67%）」）。母数だけの数字や、割合だけの数字を単独で書かない。
2. 統計的な有意差を主張しない。「有意に改善」「効果が確認された」と書かない。
3. 「症状が改善する」「治る」「効果がある」と書かない。書けるのは「参加者の主観的な実感」と「満足度」まで。
4. Q8（プログラム以外で影響したこと）で「特になし」以外を選んだ人数を必ず併記する。比較する集団がない調査のため、変化をプログラムの成果と断定しない。
5. 自由記述は良い評価だけを抜き出さない。否定的な意見も件数とともにそのまま載せる。
6. 回答が5人未満の項目は、個人が特定されうるため割合を出さず件数だけにする。
7. 事後だけに回答があり事前がない人は、変化の集計から除外し、その人数を明記する。

# 出力
- 見出しごとに表と箇条書きでまとめた報告書のたたき台（Markdown）
- 数字の根拠がわかるよう、各表に母数の行を入れる
```

## 補足：なぜ「文言を変えるな」を何度も書いているか

エージェントは親切心で言い回しを整えたり、選択肢を足したりします。
このアンケートは**事前と事後で同じ質問をして差を見る**設計なので、
片方だけ文言が変わると、その設問は集計に使えなくなります。
プロンプトから「必ず守ること」の項目は削らないでください。
