### 2. 見本データの連続日数テストが日本のタイムゾーンで失敗する

- 修正前の `pnpm test` は 39 files / 397 tests 中、`src/lib/smartphone-test-data.test.ts` の F-7 だけが失敗した。
- 原因は、`YYYY-MM-DD` をローカルの0時として作った後に `toISOString()` でUTCへ戻していたこと。日本などUTCより進んだ環境では前日になり、連続日を認識できなかった。
- テスト内の独自計算を削除し、製品が実際に使う `buildWeeklySummary` で「続けて記録できた日 / 最長3日」が出ることを検証するようにした。
- 記録がない日を含む見本であることも、同じ集計結果の `recordedDays < daysInRange` で確かめる。
