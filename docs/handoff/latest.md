## 今回実装したタスク

`use-cinematic-timeline.ts` の `setInterval`（32ms ごとに経過時間を状態へ書く）をやめ、**React の状態として持つのは段（phase）だけ**にした。段の中の進み具合は `performance.now()` から読む関数（`CinematicProgress`）としてシーンへ渡し、読む側が `useFrame` の中でその場で呼ぶ。**時計が `performance.now()` なので、どの `useFrame` が先に走っても値がずれない**（r3f の `useFrame` は子から先に登録されるため、親が書いて子が読む作りにすると1フレーム古い値を読む）。

### 進み具合を読んでいた側の作り替え（3種類）

1. **段だけで決まっていたもの**は、段から出す純関数（`shelfTAt` / `shelfGlowAt` / `spineGlowAt` / `isShelvedPhase`）に寄せて `useFrame` の中で呼ぶ。
2. **連続して変わる見た目**は、毎フレーム直に書き換える。めくれるページ（位置・回転）、机の接地影の濃さ、背表紙ラベルのにじみ（DOM の `textShadow`。値が 0.01 以上変わったときだけ触る）、`GlowSprite` 3枚の濃さ。`GlowSprite` は `intensity` に関数も取れるようにし、関数のときは板の `visible` と `opacity` だけを毎フレーム書き換える（**0 のときは `visible=false` にするので、濃さ0の板を塗る回数は増えない**）。
3. **段の途中で1回だけ切り替わるもの**は、その1回のためだけに真偽値の状態を残した。書いた行の本数（最大4回）、本を閉じる途中で行を消す位置、棚側の接地影を出す境目（0.75）、棚に収まった本を出す境目（0.88）。**メッシュの増減や DOM の中身が変わるところなので、描き直しそのものが要る。**

### 効果音は描画から切り離した

以前は「進み具合が窓（例 0.18〜0.24）に入ったら鳴らす」判定を、状態が更新されるたびに走らせていた。進み具合を毎フレーム見る作りに移すと、**端末が重くてフレームが飛んだときに窓ごと飛び越えて鳴らない。** 合図の位置（段と段の中の位置）を `SOUND_CUES` の表にし、演出開始からのミリ秒へ直して `setTimeout` で予約する形にした。**鳴らす時刻はタイムラインどおりのままで、鳴る条件（音が入で、かつ鳴らせる状態）は発火時に見る**ので、途中で音を入にしたときに以降の合図だけ鳴る挙動も変わっていない。

**予約したタイマーは、主スレッドが詰まったときや画面が裏へ回ったときに溜まってからまとめて発火する。** 音は鳴らす時点の音声時計（`ac.currentTime`）へ載るので、そのまま鳴らすと7.4秒に散っている合図が一度に重なる。**演出の時刻から 400ms 以上離れた合図は捨てる**（`shouldPlaySoundCue`）。捨てる幅は合図どうしの最小間隔（0.65秒）より小さいので、2つ以上がまとめて鳴ることはない。**以前の窓方式も遅れた合図は落としていた**ので、落とす挙動そのものは変わっていない。

## 引き継ぎ事項・注意点

### 演出の進み具合を読む作りが変わった

- **`useCinematicTimeline` は `{ phase, progress }` を返す。** `progress.value()` は「いまの段の中の 0–1」、`progress.elapsed()` は「演出開始からのミリ秒」。**どちらも `useFrame` の中から呼ぶ。** レンダー中に呼ぶと、その値は次の描き直しまで固定される。
- **段だけで決まる値は、`use-cinematic-timeline.ts` の純関数に置いてある**（`shelfTAt` / `shelfGlowAt` / `spineGlowAt` / `isShelvedPhase`）。シーンと本と棚の3か所で同じ計算をするので、そこへ足す。
- **段の途中で見た目が切り替わる新しい要素を足すときは、まず「毎フレーム直に書き換えられるか」を見る。** メッシュの増減や DOM の中身が変わるものだけ、境目の真偽値を状態にする。状態を1つ増やすと、その境目でシーン全体が描き直される。
- **効果音を足すときは `SOUND_CUES` に行を足し、`archive-scene.tsx` の `SOUND_PLAYERS` に鳴らすものを書く。** 進み具合を見て鳴らす形には戻さない（フレームが飛ぶと鳴らない）。**合図どうしの間隔は `SOUND_CUE_GRACE_MS`（400ms）より広く取る。** 詰めると、タイマーが遅れたときに束で鳴る可能性が戻る（テストが落ちる）。
