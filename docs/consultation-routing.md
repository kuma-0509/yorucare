# 相談窓口導線の設計

最終確認日: 2026-08-02
状態: 完了

## 1. 目的

利用者がどのタブを開いていても、スマートフォンから少ない操作で公的な相談先へ到達できるようにする。

この導線は、ヨルケアによる診断、治療、処方、危機判定、24時間監視、相談員による対応を提供するものではない。

## 2. 常設する導線

- 全タブ共通のヘッダー右上に `相談先` ボタンを表示する
- ボタンを押すと、画面内のダイアログで相談先を目的別に表示する
- 記録前、記録後のコンパクト表示、記録一覧、セルフケア、ふりかえりのすべてから同じ操作で開けるようにする
- 44px以上の操作領域を確保し、キーボード操作と読み上げに対応する

## 3. 表示順

1. 命や身体に差し迫った危険: 救急・消防の119、事件・事故の110
2. つらい気持ちを今すぐ話したい: 厚生労働省掲載の `#いのちSOS` と `まもろうよ こころ`
3. 仕事や復職の悩み: 厚生労働省 `こころの耳` の相談窓口
4. 診断、治療、薬の相談: 主治医または医療機関へ相談する案内

緊急通報と一般相談を混同させず、利用者自身が状況に近いものを選ぶ。アプリは入力内容から危険度を推定しない。

## 4. データ境界

- ダイアログを開いても端末内の記録を読み取らない
- 記録本文、選択値、端末IDを相談窓口へ送信しない
- 相談先の表示やクリックを匿名利用イベントとして送信しない
- 電話発信と外部サイトの表示は、本人がボタンを選んだ場合だけ端末へ依頼する
- 外部サイトへ移動した後は、その提供者の利用規約と個人情報の取扱いが適用される

## 5. 受付条件の扱い

電話番号と受付条件は変更される可能性がある。公開前と定期確認時に公式ページで見直す。画面上でも最新の受付状況を公式ページで確認するよう案内する。

## 6. 受入確認

- 全タブの上部に `相談先` が常設されている
- スマートフォン幅でボタン、見出し、電話番号が折り重ならない
- ダイアログ内が縦にスクロールでき、下端の説明まで読める
- 119、110、#いのちSOSが正しい `tel:` URLを持つ
- 外部リンクが厚生労働省のHTTPSページに限定されている
- ダイアログを閉じると元の入力状態へ戻れる
- ブラウザコンソールにエラーがない
