# ヨルケア スマホ実機テストチェックリスト

**目的**: 公開 URL 上で、毎日 1〜2 分の記録体験がスマホで使えるかを検証する。
**対象**: 現行の `main`（Phase 1 MVP の記録・一覧・グラフ ＋ Phase 2 P1 の 3 段階の入口、目標のふりかえり、自分メンテ、週のまとめ、積み重ね表示 ＋ アンケート反映分の控えたいこと、グラフの重ね表示、お薬メモ、お薬の書類）
**想定時間**: 最短ルート約 5 分 / 全項目約 50〜60 分

**判定の基準**（`docs/phase2-plan.md` 3.3 節）

- 5 人中 4 人以上が、補助なしで基本記録を **2 分以内** に保存できる。
- 5 人中 4 人以上が、過去の記録から **週の状態を振り返る場所** へ到達できる。
- データ消失、意図しない共有、保存不能、相談導線へ到達できない問題を **重大不具合** とする。

| 0-6 | 記録の書き方を確認する — **入力した内容そのもの（メモ本文、目標の文面、選んだ気持ち、しんどさの自由記述、感想）は結果に書かない**。書くのは操作と起きたことだけ（→ K 章） | ☐ |

**注意（データの前提）**

- データは **この端末のこのブラウザだけ** に保存される。
- 別端末・別ブラウザ・キャッシュ削除でデータは共有されない / 消える可能性がある。
- テスト用のダミーデータで実施する。実際の健康・服薬・面談内容は入力しない。
- **お薬メモ（A-12〜A-15）にも実際の処方内容を入れない。** 動作確認はダミーの文字列で行い、確認後に消す。
- **お薬の書類（A-16〜A-24）も実際の処方箋・お薬手帳を使わない。** 中身が分かっても差し支えないダミーのPDFを2つ（差し替えの確認用）と、PDF以外のファイル1つ、5MB超のファイル1つを事前に用意し、確認後に消す。

## 「不具合ではない」こと

| 現象 | 理由 |
|------|------|
| ログイン画面がない | Phase 1 スコープ外 |
| 一覧が直近 7 日しか出ない / それより前を編集できない | 直近 7 日のみ表示・編集可 |
| 別端末でデータが見えない | この端末のブラウザ内にだけ保存する |
| ヨルケアから外部 AI へ自動送信されない | 本人が全文を確認して共有先を選ぶ形だけを用意している |
| 「いま何日続けて書けているか」が出ない | 中断を失敗として見せないため、中断で減らない累計だけを出す |
| 節目のねぎらいが毎日出ない | ちょうど届いた日だけ出す |
| 前日の目標のふりかえりが出ない日がある | 前日に目標を書いた日だけ出す |
| 自分メンテのカードが出ない | その日の状態（3 段階）をまだ選んでいないとき |
| 週のまとめに割合（％）が出ない | 母数の小さい割合を避け、日数で示す |
| リマインド通知がない | `docs/reminder-decision.md` の Gate 2 を満たすまで実装しない |
| 「今日は控えたいこと」に、守れたかを選ぶ操作がない | 守れなかった日を失敗として残さないため、実施の可否を記録しない |
| 「今日は控えたいこと」が出ない日がある | 自分で指定した状態と、その日に選んだ状態が合ったときだけ出す |
| 重ねたグラフに相関の数値が出ない | 一方が他方の原因だと読める数値を出さないため、目盛りを並べるだけにしている |
| お薬メモが「生成AIなどへ共有」の項目に出てこない | 共有文は記録と登録簿だけから組み立てる。お薬メモは端末の外へ出す手段を持たない |
| お薬の書類がバックアップファイルに入らない | 中身がファイルであり、最も個人を特定しやすいため端末内だけに置く。元のPDFは本人が保管する前提 |
| 2枚目の書類を選ぶと、保存の前に確認が入る | 前の書類を黙って上書きしないため、増やすか差し替えるかを本人が選ぶ |
| しんどさのサインに感情の語（強い不安 等）がない | 感じている気持ちは「気持ち」のラベルで選ぶ。サインは体と生活に出た変化だけを扱う |
| 過去に選んだサインの語が、今は選択肢にない | 選択肢から外しただけで、保存済みの記録はそのまま残り一覧で読める |
