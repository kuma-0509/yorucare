# 外部データの利用許諾の扱い

最終確認日: 2026-08-17
状態: ダミーデータで開発し、根拠が確認できたデータだけを足す方針で確定

## 1. 結論

ヨルケアが表示する外部データは、次のいずれかの根拠が確認できたものだけとする。

1. オープンデータカタログに掲載され、許諾なく利用できる（`openDataCatalog`）
2. 掲載元へ個別に申請し、許諾を得た（`permissionGranted`）

根拠が未確認（`unverified`）または許諾が必要でまだ得ていない（`permissionRequired`）データは、開発期間中も含めて表示しない。プロトタイプは First Stage で一般公開されるため、「開発中だけ実データで動かし、公開直前に差し替える」進め方は取らない。差し替え漏れが起きたときの影響が、得られる開発上の利点に見合わない。

現在の実装は、外部データを一切含まないデモデータだけで動く。

## 2. 運用ルールではなく型で保証する

この方針は `docs/ai-consent-decision.md` と同じ考え方で担保する。運用の申し合わせにすると、あとから誰かが破れる。

- `DataSource.permissionBasis`（`src/lib/support/types.ts`）を**必須**にする。省略できると、根拠を確かめないまま実データを載せる実装ができてしまう。
- 根拠は自由な文字列ではなく閉じた集合にする。「たぶん大丈夫」を書けないようにする。
- `isPubliclyUsable()` の判定を1か所に閉じ込め、呼び出し側で条件を書き直せないようにする。
- アダプター（`src/lib/support/adapter.ts`）は、根拠が確定していないデータの読み込み自体を `PERMISSION_UNCONFIRMED` で拒否する。画面側の分岐ではなく、データが入ってこないことで担保する。
- 実データに `demoOnly` を付け替えて通す抜け道も塞ぐ。

判定はテスト（`src/lib/support/search.test.ts` の「利用の根拠」）で固定する。

## 3. 「引用」には当たらない

著作権法上の「引用」として許諾不要にできるのは、引用部分があくまで補足であり、自分の著作物が主である場合に限る。

ヨルケアの支援先検索は、施設情報そのものを検索・絞り込み・並べ替えの対象とする中核コンテンツである。補足ではないため、引用として扱えない。出典を書けば使える、とは考えない。

## 4. 区市町村・他道府県のデータ

都のオープンデータカタログの扱いは、区市町村や他の道府県のデータには及ばない。掲載元ごとに利用条件を確認し、必要なら個別に許諾を取る。

検索の設計上、市区町村ごとのデータが揃っていなくても壊れない。都道府県全域が対象の窓口は、市区町村を選んでも候補に残る（`municipalityRank`）。条件を確認できた自治体から1件ずつ足していける。

## 5. 接続前の確認手順

掲載状況の調査は応募提出後に行う。提出時点はデモデータのまま出す。表示されるデータが変わらないため、調査の前後で画面の安全性は変わらない。

`PLANNED_TOKYO_DATASETS`（`src/lib/support/adapter.ts`）の各データセットについて、次を確認してから `permissionBasis` を書き換える。書き換えても掲載元の条件が変わるわけではないので、確認した結果だけを反映する。

1. そのデータがオープンデータカタログに掲載されているか。掲載されていれば、そのページのライセンス表記を確認する。
2. 個別のライセンス規定が書かれている場合は、カタログ全体の条件ではなくそちらに従う。
3. カタログ外の場合は、掲載元へ利用許諾を申請する。得られるとは限らない。
4. 許諾が得られない、または収録までに確認できない場合は、そのデータセットを使わない。別の、条件が確認できたデータへ切り替える。
5. 確認できたら `permissionBasis`、`referenceUrl`、`updatedAt`、必要なら `license` を実際の値で埋める。

ライセンス表記が必要な場合は、ダイアログ内の「データについて」に表示する（表示側は実装済み）。

## 6. 運動の選択肢について

「公園まで散歩する」「近隣のスポーツ施設を使う」などの選択肢は、現在いずれも一般的な文言だけで、施設データを含まない（`src/lib/selfcare/movement-config.ts`）。そのため利用許諾の対象になっていない。

実在の行き先を出す場合は、支援先データと同じ手順で根拠を確認してから足す。

## 7. 画面での開示

ダイアログ内の「データについて」に、提供者・データセット名・更新日・種別・**利用の根拠**・ライセンス・参照URLを表示する。接続を予定しているデータについても、現在の根拠（確認済みかどうか）を並べて示す。

更新日が確認できない場合は、利用前に公式サイトか電話で最新の情報を確認するよう案内する。
