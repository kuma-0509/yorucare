# うつ病診療ガイドライン2025 — ヨルケア提案用エビデンス抜粋

**出典:** 日本うつ病学会「うつ病診療ガイドライン2025」  
**原PDF:** `docs/evidence/guideline2025.pdf`（元ファイル: Downloads/guideline2025.pdf）  
**用途:** ヨルケア提案・事業計画の**背景根拠**として引用する。診断・治療の代替ではないことを必ず併記する。

---

## 0. 引用時に必ず守る免責・位置づけ

### ガイドライン自体の免責

- 法的拘束力はない。医師の裁量を制限しない。標準推奨は出発点であり唯一の正解ではない
- 治療を決定づけるものではない。医療訴訟の根拠にはならない

### ヨルケア提案文に必ず入れる注意書き（テンプレ）

> ヨルケアは、就業者の自己記録・セルフケア支援ツールであり、うつ病の診断・治療・処方判断を行う医療行為ではない。本資料は日本うつ病学会「うつ病診療ガイドライン2025」の記述を、生活習慣・自己モニタリング・職場復帰支援の文脈で整理したものであり、ガイドラインの推奨をそのまま製品機能の医学的効能として主張するものではない。症状の悪化・自傷念慮等がある場合は、医療機関への相談が必要である。

## 1. ヨルケアに対応する定義

| 用語 | ガイドライン上の要点 | ヨルケア提案での引用例 |
|------|----------------------|------------------------|
| 閾値下の抑うつエピソード | DSM-5-TR 9項目中5項未満だが、2〜4項目が2週間以上持続（うち1つは抑うつ気分または興味・喜びの喪失） | 診断前・軽い不調段階でも、本人の記録と早期セルフケアが背景づけに資する（診断・治療の代替ではない） |
| 共同意思決定（SDM） | 患者と治療者が情報を共有し、価値観・希望・生活背景を踏まえて方針をともに決定。受容性と継続性を高めるうえで重要 | 通院・服薬の意思決定は医師領域。ヨルケアは本人の価値観・生活背景を整理する記録として、SDMの準備・補助に使える |
| 測定に基づく診療（MBC） | 標準化された自己記入式・客観的評価尺度で治療反応を定量的に測定し治療計画を動的調整。SDMをデータで実践する基盤 | 医療のMBCを代替しないが、気分・睡眠・服薬・困りごとの継続記録は、受診時の情報共有・自己洞察の材料になる |
| 心理教育 | 病態・治療・予後・再発予防・生活上の工夫などを提供し、理解と主体的対応を促す。SDMの基盤 | 記録項目（睡眠・リズム・「できたこと」）は、生活上の工夫を日常化するセルフケア支援として位置づけられる |
| 基礎的介入 | 支持的傾聴、生活習慣の調整・休養、心理教育など。軽度うつ病では単独で改善することもある | 就業中の生活習慣調整・休養・自己理解は基礎的介入の延長線上。ヨルケアは非薬物の日常支援として提案可能 |
| リカバリー | 症状消失にとどまらず、望む生活の再構築と社会的機能の回復まで含む | 「できたこと」「困りごと」の記録は、社会的・職業的機能の回復を本人が振り返るセルフケア材料として提案できる |

## 2. CQ1-4 うつ病治療の基本的な進め方

**使える要点**

1. 初期面接で困りごとに焦点を当て、患者治療者関係を構築
2. 診断の告知および基礎的介入
3. SDM（病状・選択肢・予想経過の説明と共同決定）
4. 症状・治療反応を評価尺度で定期評価し共有する（MBC）
5. 抗うつ薬の効果判定は治療開始後2〜4週で評価することが望ましい

**提案への接続**

- 継続的な自己記録は、MBCが重視する「観察と共有」の本人側の日常版として提案可能（医療用尺度の代替ではない）
- 睡眠の確保・悪循環の可視化は心理教育の文脈と整合
- 睡眠・覚醒リズムの改善は基礎的介入で重視される（CQ1-9参照）

---

## 3. CQ1-9 望ましい生活習慣

抑うつ症状の経過に関与するため、生活習慣（ライフスタイル）の要因に配慮することが望ましい。

| 領域 | 要点 |
|------|------|
| 喫煙・飲酒 | 回避が最も望ましい |
| カフェイン | 不眠・不安を助長しない範囲に |
| 睡眠 | 朝は一定時間に起床して外光に当たる等、睡眠衛生的アドバイス |
| 運動 | 適切な身体活動は抑うつ症状減少と関連。有酸素運動の有効性も指摘 |
| 体重 | 適正化を含む生活習慣改善は症状軽減と関連 |

**ヨルケア提案1行:** ガイドラインが生活習慣配慮を基本とするなか、ヨルケアは睡眠・服薬・気分・「できたこと（行動）」を就業者が日常記録するセルフケア支援として位置づけられる（治療の代替ではない）。

## 4. 第2章 軽度うつ病（CQ2-1 / CQ2-2）

### CQ2-1

- 軽度うつ病では支持的傾聴、生活負担軽減、心理教育など基礎的介入が治療の根幹
- 閾値下の抑うつエピソードはうつ病ではないが軽視してはならない
- 頑健な治療選択肢が確立されていないため SDM が重要
- 睡眠状態、アルコール・カフェイン、ストレス因子等の把握が必要

### CQ2-2

1. 基礎的介入（支持的傾聴、生活負担軽減、心理教育）を行う
2. 新規抗うつ薬は治療選択肢のひとつ
3. CBT・集団/ガイド付きプログラム・運動療法もそれぞれ選択肢のひとつ
4. サプリメント・保健機能食品は積極的には使用しない

**基礎的介入の詳細:** 規則的な食事・睡眠衛生、断酒、禁煙、カフェインコントロール、体重適正化、休養、負担軽減。軽度うつ病はこれだけで十分改善することもある。

**ヨルケア提案1行:** CQ2-2が基礎的介入を第一に位置づけることと整合し、ヨルケアは非薬物の日常セルフケアを就業文脈で支援する（CBT・運動療法・抗うつ薬の代替ではない）。

---

## 5. 第8章 不眠症状を伴ううつ病（CQ8-1 / CQ8-2 / CQ8-5）

### CQ8-1

- 不眠はうつ病の8〜9割にみられ、寛解後も残遺しやすく再発リスク因子
- 不眠の評価は急性期のみならず維持期でも重要
- 就寝・起床時刻、入眠潜時、食事・入浴、就寝前のスマホ使用等を確認
- 就労世代は平日睡眠不足→週末寝だめパターンが多い。1週間を通じた規則的な睡眠・覚醒リズムが重要
- 1週間以上の睡眠・覚醒リズム表。必要に応じアクチグラフやスマートウォッチも評価の一助

### CQ8-2 / CQ8-5

- CBT-I（心理教育・睡眠衛生、睡眠スケジュール法など）は不眠症状を伴ううつ病で有効性が示されている
- 「行うことを提案する」（国内では保険適用外・実施施設が限られる点に留意）

**ヨルケア提案1行:** 睡眠・覚醒リズムの自己記録は、受診前の整理・本人の気づきに資する。CBT-Iそのもの・診断の代替ではない。

---

## 6. トピックス1 閾値下の抑うつエピソード

- 機能障害・QOL低下、将来のうつ病発症リスク（メタ解析 RR≈1.95）
- 薬物療法は積極的には検討せず、非薬物療法（特に個人CBT、アクセス困難ならインターネット支援型CBT）を検討。SDMが望ましい
- 非薬物療法は抑うつ症状軽減・うつ病発症予防と関連する報告あり

**ヨルケア提案1行:** 閾値下段階では非薬物・早期支援・SDMが推され、セルフモニタリングと生活リズム記録は一次予防・早期気づきのセルフケア文脈で提案可能。

---

## 7. トピックス5 労働者のうつ病

- 復職後再休職49.3%、再休職者の85.2%が3年以内に再発、という規模感の記述あり
- 社会機能・職場適応、職場連携が特に重要
- 休業中は状態を定期的に把握し、回復と職場再適応の準備を評価
- 復職準備評価に企業が生活記録表を参考にする例あり
- 復職準備の観点: 生活リズムの安定（定時起床、日中外出・軽運動、夜の睡眠安定）、日常の自己管理、気分の安定／気持ちと思考の整理
- 本人・主治医・企業（人事・上司・産業保健）の連携が不可欠

**ヨルケア提案1行:** 日記は生活リズム・自己管理を可視化する就業者向け記録として、本人側の情報整理・受診準備・再発予防のセルフモニタリングに使える（診断書・治療判断の代替ではない）。

## 8. 機能マッピング（提案用クイック参照）

| ヨルケア機能 | 主な根拠 | 言い方 OK | 言い方 NG |
|-------------|---------|-----------|-----------|
| 気分記録 | MBC、CQ1-4、CQ2-1 | 自己洞察・受診時の情報整理 | うつ病診断・治療効果判定 |
| 睡眠記録 | CQ1-4、CQ1-9、CQ8-1 | 睡眠衛生・覚醒リズムの振り返り | 不眠障害の診断・CBT-I |
| 服薬記録 | CQ1-4、トピックス5 | 服薬の自己管理 | 処方変更の判断 |
| しんどさのサイン | CQ1-4（早期悪化徴候） | 早期気づき・相談判断の補助 | 自殺リスク評価・危機介入 |
| できたこと | リカバリー、CQ2-2 | 社会的機能回復のセルフ振り返り | 精神療法の実施 |
