# ヨルケア 5か月間オンラインプログラム — 確定仕様

作成日: 2026-07-12  
文書種別: 実施・研究・安全管理に関する確定仕様  
原資料: `yorucare-5month-program-spec.pdf`（`ヨルケア5か月間オンラインプログラム.pdf`）

対象者への参加提案書・プレゼン原稿を書くときは、事業内容（VHA）・医学根拠（ガイドライン）に加え、**本仕様を正本として**時間・負担・プライバシー・医療境界・参加条件を正確に反映する。

---

## 1. 1回の所要時間

### 火曜・木曜：夜の運動

| 項目 | 内容 |
|------|------|
| 1回 | 20分 |
| 内容 | スマートフォンを閉じる準備／セルフマッサージ／ゆったりしたストレッチ／呼吸法／就寝時間の確認 |
| 参加の柔軟性 | カメラOFF可・座ったまま可。火・木の両方必須ではない（体調・予定に合わせて参加可） |

### 日曜：疲労回復セッション

| 項目 | 内容 |
|------|------|
| 1回 | 20分 |
| 内容 | セルフマッサージ／ゆったりしたストレッチ／呼吸法／1週間の疲れを整える運動 |

### 日曜：振り返りプログラム

| 項目 | 内容 |
|------|------|
| 1回 | 25分 |
| グループ | 原則3名（1人あたり毎回5分話せる時間を確保） |

**進行**

| 時間 | 内容 |
|------|------|
| 0〜3分 | 挨拶・進行説明（司会） |
| 3〜6分 | アプリ記録を見ながら、各自で振り返る内容を整理 |
| 6〜21分 | 1人5分ずつ振り返り |
| 21〜25分 | 感想・終了案内 |

**1人5分で話す内容**

- 今週の状態
- 来週取り組むセルフケア
- 今週できていたので、維持したいこと

うまく話すことや深い悩みを話すことは求めない。アプリの記録を参考に、自分の状態と次の行動を整理する時間とする。

### 日曜の合計時間

- 疲労回復セッション：20分
- 振り返りプログラム：25分
- **合計：45分**

### アプリ記録

| 項目 | 内容 |
|------|------|
| 1日 | 1〜2分 |
| 記録項目 | 気分／睡眠／服薬／しんどさのサイン／できたこと／必要に応じた特記事項 |
| 義務 | 毎日の入力は義務ではない。書けない日があっても再開できる |

## 2. 参加者の負担

すべてのプログラムに参加した場合の**1週間の目安**：

| 内容 | 時間 |
|------|------|
| 火曜の夜運動 | 20分 |
| 木曜の夜運動 | 20分 |
| 日曜の疲労回復・振り返り | 45分 |
| アプリ記録 | 週7〜14分 |
| **合計** | **週約92〜99分** |

火曜または木曜のどちらか一方のみの場合：**週約72〜79分**。

欠席や記録の中断だけを理由に、プログラム参加を終了させることはない。

---

## 3. アンケート負担

### 必須アンケート（合計3回・5か月で45〜55分程度）

| 実施時期 | 内容 | 所要時間の目安 |
|----------|------|----------------|
| 参加前 | 基本情報、睡眠、気分、仕事への活力、現在の困りごとなど | 15〜20分 |
| 2.5か月時点 | 各評価項目、参加状況、途中経過 | 10〜15分 |
| 5か月終了時 | 各評価項目、満足度、参加による変化 | 15〜20分 |

### 任意の調査

- 終了後インタビュー：希望者のみ30分程度（参加条件にはしない）
- 自由記述：各アンケート1〜2問
- 途中辞退時アンケート：3〜5分程度

## 4. 募集定員とグループ編成

| 項目 | 仕様 |
|------|------|
| 募集人数 | 21名 |
| 日曜の振り返り | 全7グループ |
| 1グループ | 原則3名 |

### 欠席が出た場合の編成ルール

| 当日の参加者 | 対応 |
|--------------|------|
| 3名 | そのまま実施 |
| 2名 | 2名で実施 |
| 1名 | 別グループと統合し、3名になるよう調整 |
| 統合すると4名 | 2名ずつの2グループに分ける |

4名で1グループは原則行わない（25分内に全員の5分振り返りを確保するため）。

統合・分割時は事前または当日に参加者へ連絡する。申込み前に「欠席状況により当日グループ変更がありうる」ことを説明する。

## 5. データ保存・閲覧仕様

データは次の3種類に分けて管理する。

### A. 本人のセルフケア記録（アプリ）

| 項目 | 仕様 |
|------|------|
| 保存場所 | 参加者本人の利用端末内 |
| 運営者による閲覧 | 原則として閲覧できない |
| 運営者への自動送信 | 行わない |
| 勤務先への共有 | 行わない |
| 支援機関への自動共有 | 行わない |
| 主治医への共有 | 本人が必要に応じて自分で見せる |
| 削除 | 本人が端末上で削除可能 |
| 機種変更時 | 原則としてデータは引き継がれない |

アプリ記録と研究用アンケートデータは分けて管理する。

### B. 研究用アンケートデータ

| 項目 | 仕様 |
|------|------|
| 氏名 | アンケートデータには保存しない |
| 識別方法 | 参加者IDを使用 |
| 氏名と参加者IDの対応表 | アンケートデータとは別の場所に保存 |
| 閲覧者 | 研究責任者および指定されたデータ管理担当者 |
| 精神科医の閲覧 | 安全確認に必要な範囲に限定 |
| 勤務先への共有 | 行わない |
| 支援機関への共有 | 本人の個別同意がない限り行わない |
| 研究発表 | 個人を特定できない集計結果として使用 |
| 録画・録音 | 原則として行わない |
| 保存期間 | 研究終了後5年間を暫定基準（最終は研究実施主体の規程と倫理審査に従う） |
| 保存期間終了後 | 復元できない方法で削除 |

### C. プログラム運営情報

氏名・連絡先・所属グループ・出欠・同意取得日・途中辞退日・（取得する場合）緊急連絡先は、研究用アンケートとは分けて管理する。

**閲覧権限**

| 役割 | 氏名・連絡先 | 研究アンケート | アプリ記録 |
|------|--------------|----------------|------------|
| セッション進行者 | 担当者に必要な範囲 | 原則閲覧しない | 閲覧しない |
| 研究責任者 | 閲覧する | 閲覧する | 原則閲覧しない |
| データ管理担当者 | 管理上必要な範囲 | 閲覧する | 閲覧しない |
| 精神科医・安全責任者 | 安全対応に必要な場合 | 必要な範囲のみ | 原則閲覧しない |
| 勤務先・外部支援機関 | 閲覧しない | 閲覧しない | 閲覧しない |

### 途中辞退時のデータ

- その時点以降のデータ取得を停止する
- 個人と結びつく研究データは、本人申し出により研究計画・同意内容に従って削除する
- 個人との対応関係をすでに削除し特定できない状態になった後は、個別削除できない場合がある（参加前に説明）

## 6. ヨルケアと医療との境界

ヨルケアは、医療機関や治療の代わりとなるサービスではない。

### 行うこと

- 一般的なセルフケア情報の提供
- セルフマッサージ、ストレッチ、呼吸法
- 睡眠や気分などのセルフモニタリング
- 1週間の状態の振り返り
- 次に試すセルフケアを決める支援
- 主治医や支援者へ相談するための情報整理
- 必要に応じた一般的な受診の勧奨
- 仲間と一緒にセルフケアを継続する機会の提供

### 行わないこと

- 病気や障害の診断
- 症状の原因の特定
- 症状悪化の医学的判断
- 薬の増量・減量・中止に関する助言
- 治療方針の決定
- 医師による診察の代替
- 24時間の相談対応
- 参加者の状態の常時監視
- 緊急時の救命や安全の保証

医学的判断を求められた場合、スタッフは診断や治療上の判断を行わない。記録を整え、主治医・医療機関へ相談するよう案内する。

---

## 7. 緊急支援との境界

ヨルケアは緊急相談窓口ではない。

- アプリ入力はリアルタイム監視しない
- アンケート回答は常時確認しない
- 夜間・休日の緊急対応を保証しない
- 緊急性がある場合は医療機関や公的緊急サービスを利用してもらう

アンケート・アプリには次を明示する：

> 回答や記録はリアルタイムには確認されません。緊急の相談や支援が必要な場合は、このアプリやアンケートを使用せず、医療機関や緊急サービスへ直接連絡してください。

## 8. ライブセッション中の安全対応（3段階）

### レベル1：通常の不調

例：疲れている／眠れない日があった／仕事に行きたくない／気分が落ち込んでいる

対応：話の整理／アプリ記録の振り返り／本人のセルフケア確認／必要に応じて主治医・支援者への相談を勧める

### レベル2：状態悪化が疑われる場合

例：数日ほとんど眠れていない／食事が取れていない／出勤できなくなっている／「消えたい」発言／普段と著しく異なる言動

対応：グループ全体の場と分けて対応／一人でいるか確認／主治医・既存支援先への相談を勧める／必要に応じて精神科医または安全責任者へ報告／同意を得たうえで家族・支援者連絡を検討／対応を記録

### レベル3：生命または身体に差し迫った危険がある場合

例：自傷・他害を今から実行する意思／具体的な方法・計画／すでに自傷や服薬過量／意識・身体の明らかな異常／安全を直ちに確保できない

対応：可能な範囲で接続維持／現在地確認／緊急サービスへの連絡を求める／本人が連絡できない場合の基準に従う／必要に応じて登録緊急連絡先・緊急サービスへの連絡を検討／研究責任者・安全責任者へ報告／対応を記録

緊急時の判断をスタッフ個人に任せないため、別途、判断フローチャートと発言例を作成する。

---

## 9. PHQ-9などの評価尺度を使用する場合

自傷や死に関する考えを尋ねる項目を含む尺度を使う場合は、事前に次を定める。

- 回答を確認する担当者
- 確認の頻度と期限
- 安全確認の対象とする回答
- 本人へ連絡する担当者
- 精神科医・安全責任者へ相談する基準
- 本人と連絡が取れない場合の対応
- 夜間・休日にはリアルタイム監視を行わないこと

これらを確定できない場合は、該当尺度を使用しない。

---

## 10. 参加前に説明する重要事項

申込み前に少なくとも以下を説明する。

1. 5か月間のプログラムであること
2. 火曜・木曜は各20分、日曜は合計45分であること
3. 日曜の振り返りは原則3名で行うこと
4. 募集定員が21名であること
5. 欠席時にグループが変更される場合があること
6. アンケートは合計3回、総負担45〜55分程度であること
7. ヨルケアは医療や緊急支援ではないこと
8. 効果や症状改善を保証するものではないこと
9. 途中で参加をやめられること
10. アプリ記録と研究データの保存・閲覧方法
11. 勤務先や支援機関へ自動的に情報共有されないこと
12. 緊急時に運営者が行える対応と、行えない対応
