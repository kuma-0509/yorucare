## 2. 届けたい対象（提案の相手像）

一番届けたいのは、**メンタル不調から復職したものの、心身の不調の波が残っている人**。

- 通勤・業務は緊張感で乗り越えられる
- 帰宅後の夜間や土日祝に気力・体力が一気に落ちる
- 「週末で回復させても、月曜日が怖い」が繰り返され、再休職のトリガーになる
- 手帳の有無・障害者雇用枠かは問わない（就労中の当事者向け提案でも同じ核）

### ヒアリングで確認した事実（一般化して提案に使える）

| 出典 | 内容 |
|------|------|
| 当事者A | 夜間のSNS閲覧（リベンジ夜更かし）が常態化し、睡眠不足・不調を招く |
| 当事者B | 会社には相談しにくい。支援面談は月1回。自作Excelで孤独に体調管理。同じ悩みを持つ人と話せることで「自分だけじゃない」と感じられる |
| 支援員 | 復職後1〜2ヶ月で体調管理記録が途切れ、不調が出る。面談は仕事ができているかの確認で精一杯で、生活面・体調まで踏み込む時間がない |

### 構造的な課題（提案の「なぜ今」）

- 現在の支援体制は**平日・日中**前提。心身が乱れやすい**平日夜間・土日祝**に機能する支援がほぼない
- 医療・福祉の手が届かない時間帯で調子を崩し、再発につながる可能性が高い
- 体調記録は続きにくい。続けられれば振り返りと相談がしやすくなる
- 既存アプリは服薬特化が多く、**体調の波・生活リズムまで一体管理**できるものが不足

## 3. サービス内容（3本柱＋アプリ）

対象: 復職後に心身の波が残る人  
提供: 福祉・医療が届かない**平日夜間・土日祝**に特化したオンライン運動・セルフケア

| 柱 | 内容 |
|----|------|
| 運動セッション | 火・木 21:00〜21:20。副交感神経を優位にするストレッチ。睡眠の質向上と翌日への回復 |
| 疲労回復セッション | 日 21:00〜21:20。1週間の疲れをリセットするセルフマッサージ・ストレッチ |
| 振り返りの会 | 日 21:25〜21:45。良かったこと・改善点・来週のネクストアクションを仲間と共有 |
| 自社アプリ（ヨルケア） | 睡眠・心身の状態・セルフケアの記録。支援者・主治医との情報共有にも活用しうる体調管理ツール |

### 差別化（提案で言い切る強み）

- **時間帯の特化**（夜間・休日）。医療・福祉と競合せず**補完**する
- YouTube動画との差: 自分に合う運動の選定が難しい／一人だと続きにくい／スマホ時間で睡眠が削れる悪循環を避けやすい
- 平日夜は入眠スイッチ、日曜は翌週への弾み、という設計

### 医療行為ではない（必ず併記）

- 治療・診断・処方の代替ではない
- 医療・福祉の空白時間を埋める**補完的な生活支援・セルフケア**

## 4. 検証・展開シナリオ（提案の誠実さ・CTA設計に使う）

### いままで

- 復職経験者・就労移行支援の支援員へのヒアリングで課題の実在を確認済み
- 既存事業: 就労移行向け運動講座（6法人・137事業所）実績あり

### これから（VHA期間イメージ）

- 約20名の実践研究
- 指標案: PHQ-9（うつ症状）・UWES-9（仕事への活力）・WHO-HPQ（パフォーマンス）・PSQI（睡眠の質）
- 募集: 契約施設・連携クリニック・障害者雇用担当経由
- 中期: 効果検証→正式化→企業・産業医・クリニック展開、アプリ連携エコシステム、500名超

### 収益（参考・本人向け提案では必須ではない）

- 1年目は無料検証フェーズ想定
- 2年目以降、月額コミュニティ等での収益化を検討
